## Course Summary & Learning Journey

The course is organized into progressive units that build skills layer by layer, always connecting technical mastery with biblical insight.

**Unit 1: Getting Started with Python**  
Installation of Python and IDLE, using the interactive shell, the `print()` function, writing scripts, and transitioning to VS Code. Biblical theme: receiving truth from the right source and moving from hearing to doing.

**Unit 2: Variables, Data Types & Input/Output**  
Variables, data types, type conversion, f-strings, escape characters, string slicing, `input()`, and commenting. Biblical themes: God’s immutability and clear communication.

**Unit 3: Data Structures & Modules**  
Lists, sets, tuples, dictionaries, and modules. Emphasis on organization, uniqueness within unity, and named identity.

**Unit 4A: Conditionals & Decision Making**  
Boolean logic, comparators, compound conditions, short-circuit evaluation, `if`/`elif`/`else`, and ternary expressions. Biblical parallel: the importance of clear, ordered choices (Joshua 24:15).

**Unit 4B: Loops & Iteration**  
`while` and `for` loops, `range()`, `break`/`continue`, nested loops. Themes of rhythm, persistence, and doing things decently and in order.

**Unit 5: Functions**  
Defining functions, parameters, return values, scope, `*args`/`**kwargs`, and building reusable code. Biblical emphasis on purpose, gifts, and diligence.

**Unit 6: Object-Oriented Programming (OOP)**  
Classes, objects, inheritance, polymorphism, encapsulation, and abstraction. Reflecting on God as the ultimate Designer.

**Unit 7: Files, Exceptions & JSON**  
Safe file operations, robust error handling, and working with JSON. Themes of diligence, resilience, and integrity.

**Later Units (8–14)**  
Advanced topics including testing and debugging (`assert`, `unittest`, `pytest`), algorithms, program architecture, and culminating projects.

Lesson Examples - Inheritance and Code Reuse

These examples show how child classes inherit from parent classes, how to override methods, and how super() helps extend parent behavior without rewriting everything.

What Is Inheritance?

Inheritance lets a child class receive attributes and methods from a parent class, then specialize them. This reduces duplication and models “is-a” relationships (a Teacher is a Person).

Example 1: Parent and Child Classes 

class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} makes a sound.")

class Dog(Animal):
    def speak(self):
        print(f"{self.name} says Woof!")

class Cat(Animal):
    def speak(self):
        print(f"{self.name} says Meow!")

Dog("Fido").speak()
Cat("Luna").speak()
Animal("Creature").speak()

Output:

Fido says Woof!
Luna says Meow!
Creature makes a sound.

Example 2: Using super() 

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"I am {self.name}, age {self.age}."

class Student(Person):
    def __init__(self, name, age, grade):
        super().__init__(name, age)  # initialize parent attributes
        self.grade = grade

    def introduce(self):
        base = super().introduce()
        return f"{base} I am in grade {self.grade}."

s = Student("Ava", 15, 10)
print(s.introduce())
print(s.name, s.age, s.grade)

Output:

I am Ava, age 15. I am in grade 10.
Ava 15 10
Tip: super() calls the parent version so you can reuse it and add only what is new.

Example 3: Overriding and Extending Behavior 

class Vehicle:
    def __init__(self, brand):
        self.brand = brand

    def description(self):
        return f"Vehicle brand: {self.brand}"

class Car(Vehicle):
    def __init__(self, brand, doors):
        super().__init__(brand)
        self.doors = doors

    def description(self):
        return f"{super().description()}, doors: {self.doors}"

print(Car("Honda", 4).description())

Output:

Vehicle brand: Honda, doors: 4

Example 4: isinstance and Code Reuse 

class Employee:
    def __init__(self, name):
        self.name = name

class Manager(Employee):
    def __init__(self, name, team_size):
        super().__init__(name)
        self.team_size = team_size

m = Manager("Jordan", 5)
print(isinstance(m, Manager))
print(isinstance(m, Employee))  # True — inheritance relationship

Output:

True
True
Prefer inheritance for true “is-a” relationships. If you only need to reuse a feature, composition (“has-a”) may be clearer.

Lesson 004 - Methods in Classes: Talking Points & Discussion

Key talking points and discussion questions to help guide your teaching of this lesson.

Main Talking Points

  • Methods = behavior: Functions defined inside a class that act on an instance.

  • self in methods: Connects the method to that object’s attributes.

  • Calling methods: object.method(args) — Python supplies self automatically.

  • Data + actions: Good classes store state and provide clear operations on that state.

  • Return values: Methods can print, change state, return results, or all three carefully.

Discussion & Thought Questions

  • How is a method different from a regular function?

  • What errors appear if you forget self in a method definition?

  • Why might withdraw() return True/False instead of only printing?

  • Design a Student class: what attributes and methods would you include?

  • How does creation include both attributes and the ability to act/respond?

Biblical Integration

God created living things with attributes and with the ability to act. Methods are a programming picture of behavior joined to identity.

Lesson Examples - Attributes, __init__, and Encapsulation

These examples show how to initialize attributes with __init__ and self, use dot notation, and apply encapsulation to protect and organize object data.

self and __init__

  • __init__ runs automatically when you create a new object.
  • self refers to the specific instance being created or used.
  • Attributes are usually attached with self.name = ....

Example 1: Initializing Attributes 

class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

ava = Student("Ava", 10)
ben = Student("Ben", 11)

print(ava.name, ava.grade)
print(ben.name, ben.grade)

Output:

Ava 10
Ben 11

Example 2: Accessing and Modifying Attributes 

class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

acct = BankAccount("Mia", 100.0)
print(acct.owner)
print(acct.balance)

acct.balance = acct.balance + 25
print(acct.balance)

Output:

Mia
100.0
125.0
Directly changing attributes is flexible, but it can also allow invalid data (for example, a negative balance). Encapsulation helps control that.

Example 3: Encapsulation Basics

Encapsulation means bundling data and methods together and controlling how data is accessed or changed. In Python, a leading underscore signals “internal use.”

class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self._balance = balance   # conventional "protected" attribute

    def get_balance(self):
        return self._balance

    def deposit(self, amount):
        if amount > 0:
            self._balance += amount
        else:
            print("Deposit must be positive.")

acct = BankAccount("Noah", 50)
acct.deposit(20)
print(acct.get_balance())
acct.deposit(-5)

Output:

70
Deposit must be positive.
Tip: Prefer methods like deposit() over freely rewriting internal values when rules must be enforced.

Example 4: Default Attribute Values 

class Player:
    def __init__(self, name, health=100):
        self.name = name
        self.health = health
        self.level = 1

hero = Player("Grace")
print(hero.name, hero.health, hero.level)

boss = Player("Dragon", health=500)
print(boss.name, boss.health, boss.level)

Output:

Grace 100 1
Dragon 500 1

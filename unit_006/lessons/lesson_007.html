Lesson Examples - Putting It All Together with Classes

These examples combine classes, inheritance, polymorphism, encapsulation, and earlier tools (lists, loops, conditionals) into small, useful programs — plus debugging tips for OOP code.

Design First

For a simple library system, plan the “kinds of things” first:

  1. Book — title, author, availability
  2. Member — name and checked-out books
  3. Library — holds books and members, coordinates actions
Tip: If you can name the nouns in the problem, you often have your classes.

Example 1: Multiple Classes Working Together 

class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author
        self.available = True

    def checkout(self):
        if self.available:
            self.available = False
            return True
        return False

    def return_book(self):
        self.available = True

class Library:
    def __init__(self):
        self.books = []

    def add_book(self, book):
        self.books.append(book)

    def find(self, title):
        for book in self.books:
            if book.title == title:
                return book
        return None

    def available_titles(self):
        return [b.title for b in self.books if b.available]

lib = Library()
lib.add_book(Book("Pilgrim's Progress", "Bunyan"))
lib.add_book(Book("Mere Christianity", "Lewis"))

book = lib.find("Mere Christianity")
if book:
    book.checkout()

print(lib.available_titles())

Output:

["Pilgrim's Progress"]

Example 2: Inheritance + Polymorphism in One Program 

class Employee:
    def __init__(self, name):
        self.name = name

    def pay(self):
        return 0

    def label(self):
        return "Employee"

class HourlyEmployee(Employee):
    def __init__(self, name, hours, rate):
        super().__init__(name)
        self.hours = hours
        self.rate = rate

    def pay(self):
        return self.hours * self.rate

    def label(self):
        return "Hourly"

class SalariedEmployee(Employee):
    def __init__(self, name, salary):
        super().__init__(name)
        self.salary = salary

    def pay(self):
        return self.salary / 24  # semi-monthly simplification

    def label(self):
        return "Salaried"

payroll = [
    HourlyEmployee("Sam", 40, 15),
    SalariedEmployee("Taylor", 48000),
]

for person in payroll:
    print(f"{person.name} ({person.label()}): ${person.pay():.2f}")

Output:

Sam (Hourly): $600.00
Taylor (Salaried): $2000.00

Example 3: OOP + Loops, Conditionals, and Lists 

class Quiz:
    def __init__(self, title):
        self.title = title
        self.scores = []

    def add_score(self, score):
        if 0 <= score <= 100:
            self.scores.append(score)
        else:
            print("Ignored invalid score:", score)

    def average(self):
        if not self.scores:
            return 0
        return sum(self.scores) / len(self.scores)

    def summary(self):
        print(self.title)
        print("Scores:", self.scores)
        print("Average:", round(self.average(), 1))
        if self.average() >= 70:
            print("Class is passing overall.")
        else:
            print("Class needs more review.")

q = Quiz("Unit 6 Check")
for value in [88, 72, 95, -3, 61]:
    q.add_score(value)
q.summary()

Output:

Ignored invalid score: -3
Unit 6 Check
Scores: [88, 72, 95, 61]
Average: 79.0
Class is passing overall.

Example 4: Debugging OOP Code 

class Counter:
    def __init__(self):
        self.value = 0

    def increment(self):
        self.value += 1
        return self.value

# Common bug: forgetting parentheses when creating an instance
# c = Counter      # class object, not instance
c = Counter()
print(c.increment())
print(c.increment())

# Common bug: calling method on wrong type
# print(Counter.increment())  # missing instance / self

Output:

1
2
Debug checklist: Did you create an instance with ()? Did methods include self? Are attributes set in __init__? Are you calling the method on the correct object?

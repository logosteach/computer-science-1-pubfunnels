Lesson Examples - Introduction to Object-Oriented Programming

These examples introduce Object-Oriented Programming (OOP): what it is, why it helps manage complexity, and the core vocabulary — classes, objects, attributes, and methods.

What Is OOP?

Object-Oriented Programming is a style of programming that organizes code around objects — bundles of data (attributes) and behavior (methods) that model real-world or problem-domain things.

  • Organization: Related data and actions live together.
  • Reusability: One class can create many similar objects.
  • Modeling: Code can mirror students, books, animals, bank accounts, and more.
Tip: You have already used objects: strings, lists, and dictionaries are objects with attributes and methods (for example, "hello".upper()).

Example 1: Core Vocabulary

  • Class: A blueprint or template (for example, Dog).
  • Object / Instance: One specific thing made from that blueprint (for example, Fido).
  • Attribute: Data stored on an object (name, age, breed).
  • Method: A function that belongs to a class and describes behavior (bark, sit).
# You already work with objects every day:
text = "Python"
print(type(text))          # <class 'str'>
print(text.upper())        # method call
print(len(text))           # function that works with the object

scores = [88, 92, 75]
print(type(scores))        # <class 'list'>
scores.append(100)         # method that changes the list

Example 2: Procedural Style vs Object Style (Preview)

Without classes, related data can get scattered:

# Related data stored separately
student_name = "Ava"
student_grade = 10
student_gpa = 3.8

def describe_student(name, grade, gpa):
    print(f"{name} is in grade {grade} with GPA {gpa}")

describe_student(student_name, student_grade, student_gpa)

With OOP (preview of later lessons), name, grade, and GPA travel together as one object:

# Preview — full syntax comes in Lessons 2–4
class Student:
    def __init__(self, name, grade, gpa):
        self.name = name
        self.grade = grade
        self.gpa = gpa

    def describe(self):
        print(f"{self.name} is in grade {self.grade} with GPA {self.gpa}")

ava = Student("Ava", 10, 3.8)
ava.describe()

Output:

Ava is in grade 10 with GPA 3.8

Example 3: Managing Complexity

As programs grow, loose variables and long function lists become hard to track. Classes help by:

  • Grouping related state and behavior
  • Giving clear names to concepts in your problem
  • Making it easier to add features without rewriting everything
OOP is a tool, not a requirement for every tiny script. Use it when modeling “things with data and behavior” makes the design clearer.

Lesson 006 - Polymorphism and Abstraction: Talking Points & Discussion

Key talking points and discussion questions to help guide your teaching of this lesson.

Main Talking Points

  • Polymorphism: Same method name, different behavior depending on the object.

  • Method overriding: A primary way to achieve polymorphism in class hierarchies.

  • Duck typing: Python can use objects based on available methods, not only inheritance.

  • Abstraction: Expose a simple interface; hide complex internal details.

  • Practical habit: Prefer clear methods over forcing callers to manipulate internals.

Discussion & Thought Questions

  • How can a loop call area() on different shapes without special-casing each type?

  • What is duck typing, and how is it different from requiring a shared parent class?

  • Give an example of abstraction you already use (for example, print() or a car’s steering wheel).

  • When does hiding details help, and when can it confuse beginners?

  • How do diverse gifts with one purpose relate to polymorphism in design?

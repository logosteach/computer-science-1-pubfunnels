Lesson Examples - Creating Classes and Objects

These examples show how to define a class with the class keyword, create instances from that class, and understand the blueprint vs object relationship.

Class vs Instance

  • Class: The blueprint (one design).
  • Instance / Object: A concrete object created from that design (many possible).
Tip: Cookie cutter = class. Cookies = instances. Same shape, many cookies.

Example 1: Your First Class 

class Dog:
    pass   # empty for now — valid but not useful yet

# Create instances (objects)
fido = Dog()
bella = Dog()

print(type(fido))
print(fido is bella)   # False — two different objects

Output:

<class '__main__.Dog'>
False

Example 2: Multiple Instances From One Class 

class Book:
    pass

book1 = Book()
book2 = Book()
book3 = Book()

library = [book1, book2, book3]
print(len(library))
print(all(isinstance(b, Book) for b in library))

Output:

3
True

One class definition; many independent objects.

Example 3: Naming Conventions 

# Class names use CapWords (PascalCase)
class StudentRecord:
    pass

class BankAccount:
    pass

# Instance variables use snake_case
alice_record = StudentRecord()
checking = BankAccount()
Always use class ClassName: with a capital letter to start class names. This is the standard Python style and helps readers spot classes quickly.

Example 4: Class Is the Type of Its Instances 

class Cat:
    pass

whiskers = Cat()
print(type(whiskers))
print(whiskers.__class__)
print(isinstance(whiskers, Cat))

Output:

<class '__main__.Cat'>
<class '__main__.Cat'>
True

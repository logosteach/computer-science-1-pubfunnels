The Adventurer’s Pack

A text-based inventory game that teaches you how to work with lists in Python.

Skills you will practice:

  • Creating and using lists
  • Looping through a list with indexes
  • Positive indexing and negative indexing
  • append(), insert(), pop(), del, and len()

How to play:

  1. You start with an empty backpack.
  2. Use the menu to add, insert, remove, and examine items.
  3. Try both positive indexes (0, 1, 2…) and negative indexes (−1, −2…).
  4. Watch how len() tells you how full your pack is.
  5. The backpack can hold a maximum of 8 items.

Note to the student:

This game has no persistence. That means the backpack only exists while the program is running. As soon as you quit or close the program, every item disappears and the list is gone. The next time you run the program you will start with an empty backpack again. Later we will learn how to save data so it can remember information between runs.

Suggested Reading Plan

Chapter 1 — Foundations and Essentials in Python, broken into short sittings. Stay with one focus each day.

7 days

Day 1

Start the adventure

Read the Chapter 1 introduction and the opening pages that welcome you to the course and the textbook.

Focus: Know why this chapter exists and finish installing Python, IDLE, and VS Code if you have not already.

Day 2

Talking to the shell

Read the sections on the Python shell, chevrons >>>, print(), characters, strings, and string literals.

Focus: Run a few print() lines in the shell. Notice the difference between a character and a string.

Day 3

Names and types

Read the sections on variables, the assignment operator =, integers, floats, and type().

Focus: Create three variables (an int, a float, and a string) and check each one with type().

Day 4

Doing the math

Read the sections on order of operations, true division /, floor division //, and modulus %.

Focus: Predict 15 / 3, 15 // 3, and 23 % 17 before you run them. Then check yourself in the shell.

Day 5

Listening and joining

Read the sections on input(), int(), float(), str(), concatenation, and f-strings.

Focus: Remember that input() always returns a string. Convert before you do math. Try one concatenated string and one f-string.

Day 6

Shaping the text

Read the sections on escape characters, white space, indexing, slicing, mutable vs. immutable, .replace(), and .strip().

Focus: Print a staircase with \n and \t. Try to change name[0] and notice why it fails. Assign message = message.replace(...) if you want the change to stay.

Day 7

Leave a trail for the next reader

Read the sections on commenting, inline comments, and block comments. Then review the Chapter 1 vocabulary list in Before You Quiz.

Focus: Add one inline comment and one short block comment to a program you already wrote. You are not allowed to use that notebook on the quiz, so study the terms before you open the assessment.

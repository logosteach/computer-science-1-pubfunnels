Binary ↔ Decimal Converter

Practice converting positive integers and see how the math works

How the Conversion Works

Decimal → Binary
Repeatedly divide the number by 2 and record the remainders.
The remainders (read from bottom to top) form the binary number.
Example: 13 → 11012
Binary → Decimal
Multiply each bit by its place value (powers of 2) and add the results.
Place values from right to left: 1, 2, 4, 8, 16, 32…
Example: 11012 = 8+4+0+1 = 13

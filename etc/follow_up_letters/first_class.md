### Understanding the Names (A Quick Glossary)

New tools often come with names that sound mysterious at first. Here’s what they actually mean:

| Name              | Simple Definition |
|-------------------|-------------------|
| **Terminal**      | A text-based window where you type commands directly to the computer instead of clicking with a mouse. Think of it as talking to your computer in short, precise sentences. |
| **PowerShell**    | The modern command-line tool built into Windows. It is Windows’ version of the Terminal. |
| **Command Prompt**| An older Windows command-line tool. Some of you may still see it, but PowerShell is preferred. |
| **Terminal.app**  | The built-in Terminal application on macOS. |
| **Python**        | The programming language we are learning. It is designed to be readable and beginner-friendly. |
| **IDLE**          | A simple program that comes with Python. It lets you write and run Python code. “IDLE” stands for Integrated Development and Learning Environment. |
| **VS Code**       | A popular, free code editor (made by Microsoft) that many programmers use. We may use it later; it is more powerful than IDLE but also more complex at first. |
| **Shell**         | The program inside the Terminal that actually reads and runs the commands you type. |

### Terminal Commands We Used

These commands work in both macOS Terminal and Windows PowerShell (with small differences noted):

| Command          | What it does                                      | Notes |
|------------------|---------------------------------------------------|-------|
| `pwd`            | Prints the name of the folder you are currently in (“print working directory”) | Works the same on Mac and Windows PowerShell |
| `ls`             | Lists the files and folders in the current location | macOS / Linux style |
| `dir`            | Same as `ls` — lists files and folders            | Windows style (also works in PowerShell) |
| `cd foldername`  | Changes into a different folder (“change directory”) | Same on both systems |
| `cd ..`          | Moves up one folder level                         | Same on both systems |
| `cd ~` or `cd`   | Returns to your home folder                       | `cd ~` works on Mac; `cd` (alone) often works on Windows |

**Tip:** On Windows, PowerShell accepts many of the same commands that macOS uses (`ls`, `pwd`, etc.), which makes switching between systems easier than it used to be.

### The `print()` Statement and Escape Characters

We used `print()` to display text on the screen.  
We also practiced two escape characters:

- `\\` — tells Python to show an actual backslash  
- `\t` — inserts a tab (extra space)

These special codes begin with a backslash (`\`) and let us control how text appears.

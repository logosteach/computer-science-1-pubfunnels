What You Need to Know for This Exam

This assessment covers everything you’ve learned in Unit 001: Python Foundations, Tools & First Programs. You will be tested on your ability to understand, write, and debug the very first building blocks of Python programming and the tools you use every day.

Core Programming Concepts

  • IDLE’s two primary windows (Shell and Editor) and how to configure line numbers
  • Python variable naming rules and the PEP 8 snake_case convention
  • Basic print() statements, string concatenation with +, the end parameter, and converting types with str()
  • Common errors: SyntaxError vs NameError vs TypeError and what each means
  • Importing functions from the math module (especially from math import sqrt)
  • Simple expressions using ** for exponents and the order of operations
  • Creating, organizing, and moving files and folders inside VS Code
  • Evaluating the trustworthiness of VS Code extensions (downloads, reviews, publisher)

Biblical Integration

You should be able to connect these foundational programming habits to Scripture and the Christian life — careful naming (as God named and ordered creation), building on a firm foundation, wise stewardship of tools, and the difference between structure (syntax) and meaning.

Study Strategies

  • Review the objectives from each lesson — make sure you can explain them in your own words.
  • Practice writing code by hand — then test it in IDLE or VS Code.
  • Trace code on paper: draw out what happens step-by-step with different inputs and deliberately create SyntaxErrors and NameErrors so you recognize them.
  • Explain concepts out loud — teaching someone else is one of the best ways to learn.
  • Connect to life — think about how careful naming, orderly folders, and trustworthy tools relate to faithfulness, stewardship, and building on the rock.
  • Do the practice files and computer lab again if needed. Re-create the diamond, the bordered label, and the hypotenuse program from memory.

You’ve worked hard this unit — trust God, do your best, and remember that learning is ultimately for His glory!

Lesson 001 - Introduction to Functions: Talking Points & Discussion

Key talking points and discussion questions to help guide your teaching of this lesson.

Main Talking Points

  • Why functions exist: Programs need reusable, named blocks of code so we do not copy-paste the same logic everywhere.

  • DRY principle: “Don’t Repeat Yourself.” One well-written function is easier to update than ten duplicated code blocks.

  • Three big benefits: readability (clear names), reusability (call many times), and maintainability (fix in one place).

  • Real-world analogies: recipes, ATM procedures, school routines, and Python’s own built-ins like print() and len().

  • Preview of later lessons: Today is about why functions matter; defining and calling syntax comes next.

Discussion & Thought Questions

  • What problems appear when the same code is copied in many places?

  • Can you name three real-life systems that work like functions (input → process → result)?

  • How have you already used functions in Python without writing them yourself?

  • Why does a clear function name make a program easier for others to understand?

  • How does the idea of different parts working together (in the Church or in creation) connect to organizing code with functions?

Biblical Integration

God designed the world and the Church with purpose and order. Different members work together efficiently, just as functions help code work together without needless chaos or duplication.

Scripture:

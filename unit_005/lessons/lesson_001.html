Lesson Examples - Introduction to Functions

These examples introduce why functions matter, the DRY principle (Don't Repeat Yourself), and how reusable blocks of code improve readability and maintainability. We also connect real-world “function-like” systems to programming.

Why Functions Exist

Without functions, the same instructions get copied over and over. That makes programs longer, harder to read, and risky to update (fix one place and forget another).

A function is a named, reusable block of code that performs a specific task. You write it once and use it many times.

Tip: Think of a function like a recipe card: write the steps once, follow them whenever you need that result.

Example 1: Repeated Code Without Functions

Imagine greeting three students with the same message pattern:

# Without functions — code is repeated
print("Welcome to class, Alice!")
print("Please open your textbook.")
print("Have a great lesson!")
print()

print("Welcome to class, Ben!")
print("Please open your textbook.")
print("Have a great lesson!")
print()

print("Welcome to class, Cara!")
print("Please open your textbook.")
print("Have a great lesson!")

Problem: If you change the greeting, you must edit it in three places. Easy to miss one.

Example 2: The Same Task With a Function (Preview)

Here is a first look at how a function solves that problem. You will learn the full syntax in Lesson 2.

def welcome_student(name):
    print(f"Welcome to class, {name}!")
    print("Please open your textbook.")
    print("Have a great lesson!")
    print()

welcome_student("Alice")
welcome_student("Ben")
welcome_student("Cara")

Output:

Welcome to class, Alice!
Please open your textbook.
Have a great lesson!

Welcome to class, Ben!
Please open your textbook.
Have a great lesson!

Welcome to class, Cara!
Please open your textbook.
Have a great lesson!

One change inside welcome_student updates every greeting. That is DRY in action.

Example 3: Real-World Function Analogies

  • Recipe: Ingredients + steps → finished dish (inputs → process → result).
  • ATM withdrawal: You request an amount; the machine follows a fixed procedure.
  • School schedule: Each class period is a “routine” with a clear purpose.
  • Built-in Python tools: print(), len(), and input() are functions you already use.
# You have already been calling functions!
message = "Hello"
print(len(message))      # len is a function
print(message.upper())   # upper is a method (a function tied to a value)

Example 4: Readability, Reusability, Maintainability

Good functions give you three major benefits:

  • Readability: A clear name like calculate_average tells what the code does.
  • Reusability: Call the same function from many places in a program.
  • Maintainability: Fix or improve one function instead of hunting through copy-pasted code.
Avoid giant “do everything” blocks. Prefer small, purposeful functions that each do one job well.

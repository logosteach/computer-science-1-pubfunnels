Lesson Examples - Defining and Calling Functions

These examples show how to define a function with def, how to call (invoke) it, and the important difference between writing a function and actually running it.

Defining vs Calling

  • Define: Create the function using def. Python stores the instructions but does not run them yet.
  • Call: Use the function name followed by parentheses to execute those instructions.
Tip: Defining a function is like writing a name on a toolbox. Calling it is actually using the tool.

Example 1: Your First Function 

def say_hello():
    print("Hello, student!")
    print("Ready to learn Python?")

# Definition alone does nothing visible
# Now call the function:
say_hello()

Output:

Hello, student!
Ready to learn Python?

Example 2: Calling a Function Multiple Times 

def print_separator():
    print("-" * 30)

print("Section A")
print_separator()
print("Section B")
print_separator()
print("Section C")
print_separator()

Output:

Section A
------------------------------
Section B
------------------------------
Section C
------------------------------

Example 3: Functions That Perform Basic Tasks 

def show_menu():
    print("=== Study Menu ===")
    print("1. Review notes")
    print("2. Practice problems")
    print("3. Take a break")

def cheer():
    print("You can do this. One step at a time!")

show_menu()
print()
cheer()

Output:

=== Study Menu ===
1. Review notes
2. Practice problems
3. Take a break

You can do this. One step at a time!

Example 4: Common Mistakes 

def greet():
    print("Hi there!")

# Mistake 1: forgetting parentheses — this does NOT call the function
greet   # no output; just refers to the function object

# Mistake 2: calling before defining (NameError if this runs first)
# greet_early()
# def greet_early():
#     print("Too late!")

# Correct: define first, then call
greet()
Always define a function before you call it in the same file (top to bottom order). And remember: greet is not the same as greet().

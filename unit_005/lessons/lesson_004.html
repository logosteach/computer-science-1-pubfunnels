Lesson Examples - Return Values and Scope

These examples show how return sends values back from a function, how local and global scope work, and how to avoid common scope mistakes.

print vs return

  • print() displays text for humans to read.
  • return sends a value back to the caller so the program can use it later.
Tip: Prefer return when you need the result for more calculations, storage, or decisions.

Example 1: Returning a Value 

def add(a, b):
    return a + b

result = add(7, 5)
print(result)
print(add(10, 3) * 2)

Output:

12
26

Example 2: Using Returned Values in Decisions 

def is_passing(score):
    return score >= 70

quiz = 82
if is_passing(quiz):
    print("Great work — you passed!")
else:
    print("Keep practicing.")

Output:

Great work — you passed!

Example 3: Local vs Global Scope 

message = "global message"   # global variable

def show_messages():
    message = "local message"  # local variable (different name space)
    print("Inside function:", message)

show_messages()
print("Outside function:", message)

Output:

Inside function: local message
Outside function: global message

The local message only exists inside the function. The global one is unchanged.

Example 4: Common Scope Errors 

def calculate_total(price, tax_rate):
    tax = price * tax_rate
    total = price + tax
    return total

bill = calculate_total(20.00, 0.08)
print(bill)

# This would cause NameError — tax is local to the function:
# print(tax)

Output:

21.6
Variables created inside a function are local. Use return to share results with the rest of the program. Avoid relying on the global keyword unless you truly need it.

Example 5: Returning Multiple Values 

def min_and_max(numbers):
    return min(numbers), max(numbers)

scores = [88, 72, 95, 81]
low, high = min_and_max(scores)
print(f"Low: {low}, High: {high}")

Output:

Low: 72, High: 95

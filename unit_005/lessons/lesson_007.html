Lesson Examples - Putting It All Together

These examples combine functions with loops, conditionals, and data structures. You will see how to plan a small program by functions first, then implement and debug it.

Plan First: Break the Program into Functions

For a simple quiz-score tracker, plan these jobs:

  1. display_menu() — show choices
  2. add_score(scores) — collect and store a score
  3. show_summary(scores) — compute stats and print a report
  4. main() — run the program loop
Tip: If you can name each step, you can usually turn each step into a function.

Example 1: Functions + Loops + Conditionals 

def is_valid_score(score):
    return 0 <= score <= 100

def average(scores):
    if not scores:
        return 0
    return sum(scores) / len(scores)

def passing_count(scores, cutoff=70):
    count = 0
    for s in scores:
        if s >= cutoff:
            count += 1
    return count

scores = [88, 62, 95, 70, 54]
print("Average:", round(average(scores), 1))
print("Passing:", passing_count(scores))
print("Valid 101?", is_valid_score(101))

Output:

Average: 73.8
Passing: 3
Valid 101? False

Example 2: A Small Useful Program 

def display_menu():
    print("\n=== Score Tracker ===")
    print("1. Add a score")
    print("2. Show summary")
    print("3. Quit")

def add_score(scores):
    value = int(input("Enter score (0-100): "))
    if 0 <= value <= 100:
        scores.append(value)
        print("Score added.")
    else:
        print("Invalid score. Not added.")

def show_summary(scores):
    if not scores:
        print("No scores yet.")
        return
    print(f"Scores: {scores}")
    print(f"Count: {len(scores)}")
    print(f"Average: {sum(scores) / len(scores):.1f}")
    print(f"Best: {max(scores)}")
    print(f"Lowest: {min(scores)}")

def main():
    scores = []
    while True:
        display_menu()
        choice = input("Choose: ").strip()
        if choice == "1":
            add_score(scores)
        elif choice == "2":
            show_summary(scores)
        elif choice == "3":
            print("Goodbye!")
            break
        else:
            print("Please choose 1, 2, or 3.")

# main()  # Uncomment to run interactively

This program structure is easy to extend later (for example, delete a score or save to a file).

Example 3: Debugging Multi-Function Programs 

def double_all(values):
    result = []
    for v in values:
        result.append(v * 2)
    return result

def process(values):
    # Common bug: forgetting to use the returned list
    double_all(values)          # does nothing useful by itself
    return double_all(values)   # correct: capture/return the result

nums = [1, 2, 3]
print(process(nums))

Output:

[2, 4, 6]
When debugging functions: print inputs at the top, print return values before leaving, and test each function alone before combining them.

Example 4: Functions Working With Data Structures 

def tally_votes(votes):
    """Count votes for each candidate in a list."""
    counts = {}
    for name in votes:
        if name in counts:
            counts[name] += 1
        else:
            counts[name] = 1
    return counts

def winner(counts):
    """Return the candidate with the most votes."""
    best_name = None
    best_total = -1
    for name, total in counts.items():
        if total > best_total:
            best_name = name
            best_total = total
    return best_name

ballots = ["Ava", "Ben", "Ava", "Cara", "Ben", "Ava"]
results = tally_votes(ballots)
print(results)
print("Winner:", winner(results))

Output:

{'Ava': 3, 'Ben': 2, 'Cara': 1}
Winner: Ava

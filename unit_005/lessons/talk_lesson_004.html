Lesson 004 - Return Values and Scope: Talking Points & Discussion

Key talking points and discussion questions to help guide your teaching of this lesson.

Main Talking Points

  • return vs print: Print is for display; return is for sending a value back into the program.

  • Using return values: Store them in variables, pass them into other functions, or use them in conditions.

  • Local scope: Variables created inside a function exist only while that function runs.

  • Global scope: Variables defined outside functions are available more broadly — but overusing them makes programs hard to reason about.

  • Common error: Trying to use a local variable outside the function (NameError). Return the value instead.

Discussion & Thought Questions

  • When should a function return a value instead of only printing?

  • What happens to local variables after a function finishes?

  • Why can two different functions both have a variable named total without conflicting?

  • How would you write a function that returns both a minimum and a maximum value?

  • How does “returning something valuable” connect to living for God’s glory?

Biblical Integration

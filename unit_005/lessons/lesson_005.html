Lesson Examples - Advanced Function Features

These examples introduce flexible argument packing with *args and **kwargs, plus simple lambda functions for short, anonymous tasks. Use these tools carefully so code stays clear.

When Advanced Features Help

  • You need a function that accepts a varying number of values.
  • You need a tiny one-line function for sorting or mapping.
  • You want optional named options without listing every parameter.
Advanced does not always mean better. Prefer plain parameters when they keep the code easier to read.

Example 1: *args (Variable Positional Arguments)

*args collects extra positional arguments into a tuple.

def average(*numbers):
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

print(average(10, 20))
print(average(80, 90, 100))
print(average(5))

Output:

15.0
90.0
5.0

Example 2: **kwargs (Variable Keyword Arguments)

**kwargs collects extra keyword arguments into a dictionary.

def student_profile(name, **details):
    print(f"Name: {name}")
    for key, value in details.items():
        print(f"  {key}: {value}")

student_profile("Emma", grade=10, club="Robotics", city="Boise")

Output:

Name: Emma
  grade: 10
  club: Robotics
  city: Boise

Example 3: Combining Regular Parameters with *args and **kwargs 

def log_event(event_type, *messages, **meta):
    print(f"[{event_type}]")
    for msg in messages:
        print(" -", msg)
    if meta:
        print(" meta:", meta)

log_event("INFO", "User logged in", "Session started", user="noah", attempt=1)

Output:

[INFO]
 - User logged in
 - Session started
 meta: {'user': 'noah', 'attempt': 1}

Example 4: Simple Lambda Functions

A lambda is a short anonymous function for simple expressions.

square = lambda x: x * x
print(square(6))

add = lambda a, b: a + b
print(add(3, 4))

# Useful with sorted
names = ["Zara", "ben", "Amy"]
print(sorted(names, key=lambda s: s.lower()))

Output:

36
7
['Amy', 'ben', 'Zara']
Tip: If a lambda needs more than one short expression, write a normal def function instead. Clarity beats cleverness.

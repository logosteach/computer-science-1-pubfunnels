Lesson Examples - Organizing Code with Functions

These examples focus on docstrings, clear naming, breaking large problems into smaller functions, and organizing code so it is readable and intentional.

Best Practices Checklist

  • Use verb-based names: calculate_total, load_scores, display_menu.
  • Keep each function focused on one clear job.
  • Write a short docstring explaining purpose, inputs, and return value.
  • Break big tasks into smaller helper functions.

Example 1: Writing Clear Docstrings 

def celsius_to_fahrenheit(celsius):
    """Convert a temperature from Celsius to Fahrenheit.

    Args:
        celsius (float): Temperature in degrees Celsius.

    Returns:
        float: Temperature in degrees Fahrenheit.
    """
    return (celsius * 9 / 5) + 32

print(celsius_to_fahrenheit(0))
print(celsius_to_fahrenheit(100))
print(celsius_to_fahrenheit.__doc__)

Output (partial):

32.0
212.0
Convert a temperature from Celsius to Fahrenheit.
...
Tip: Good docstrings help future-you (and classmates) understand a function without rereading every line of code.

Example 2: Naming and Structure 

# Harder to understand
def f(x, y):
    return x * 0.9 if y else x

# Clearer
def apply_discount(price, is_member):
    """Return price after a 10% member discount when applicable."""
    if is_member:
        return price * 0.9
    return price

print(apply_discount(50, True))
print(apply_discount(50, False))

Output:

45.0
50

Example 3: Breaking a Larger Problem into Functions 

def get_scores():
    """Return a sample list of quiz scores."""
    return [88, 76, 94, 81]

def average_score(scores):
    """Return the average of a list of scores."""
    return sum(scores) / len(scores)

def letter_grade(avg):
    """Return a simple letter grade for an average."""
    if avg >= 90:
        return "A"
    elif avg >= 80:
        return "B"
    elif avg >= 70:
        return "C"
    else:
        return "Needs Improvement"

def report_card():
    """Build and print a short grade report."""
    scores = get_scores()
    avg = average_score(scores)
    grade = letter_grade(avg)
    print(f"Scores: {scores}")
    print(f"Average: {avg:.1f}")
    print(f"Grade: {grade}")

report_card()

Output:

Scores: [88, 76, 94, 81]
Average: 84.8
Grade: B

Example 4: Before and After Refactoring

Before (one long block):

# All logic jammed together — harder to test and reuse
scores = [88, 76, 94, 81]
avg = sum(scores) / len(scores)
if avg >= 90:
    grade = "A"
elif avg >= 80:
    grade = "B"
else:
    grade = "C"
print(scores, avg, grade)

After: separate functions (see Example 3) so each piece can be tested, reused, and understood.

If a function is hard to name, it may be doing too many things. Split it.

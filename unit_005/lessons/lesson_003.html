Lesson Examples - Function Parameters and Arguments

These examples show how to pass information into functions using parameters and arguments, including positional arguments, keyword arguments, and default values.

Parameters vs Arguments

  • Parameter: A variable name listed in the function definition (the placeholder).
  • Argument: The actual value you pass in when you call the function.
def greet(name):      # name is a parameter
    print(f"Hello, {name}!")

greet("Jordan")       # "Jordan" is an argument

Example 1: Positional Arguments

Arguments match parameters by order (left to right).

def introduce(name, age, city):
    print(f"{name} is {age} years old and lives in {city}.")

introduce("Ava", 16, "Denver")
introduce("Luis", 15, "Austin")

Output:

Ava is 16 years old and lives in Denver.
Luis is 15 years old and lives in Austin.
Order matters with positional arguments. Swapping values can produce wrong or confusing results.

Example 2: Keyword Arguments

Keyword arguments name each value so order is flexible and meaning is clearer.

def introduce(name, age, city):
    print(f"{name} is {age} years old and lives in {city}.")

introduce(city="Denver", name="Ava", age=16)
introduce(name="Luis", city="Austin", age=15)

Output:

Ava is 16 years old and lives in Denver.
Luis is 15 years old and lives in Austin.

Example 3: Default Parameter Values 

def welcome(name, course="Computer Science 1"):
    print(f"Welcome, {name}, to {course}!")

welcome("Sam")
welcome("Riley", "Python Advanced")
welcome(name="Taylor", course="Web Basics")

Output:

Welcome, Sam, to Computer Science 1!
Welcome, Riley, to Python Advanced!
Welcome, Taylor, to Web Basics!
Tip: Put parameters with defaults after required parameters: def f(required, optional="value"):

Example 4: Mixing Positional and Keyword Arguments 

def score_report(student, quiz, project, extra_credit=0):
    total = quiz + project + extra_credit
    print(f"{student}: quiz={quiz}, project={project}, extra={extra_credit}, total={total}")

score_report("Mia", 88, 92)
score_report("Noah", 80, 85, extra_credit=5)
score_report("Olivia", quiz=90, project=95, extra_credit=2)

Output:

Mia: quiz=88, project=92, extra=0, total=180
Noah: quiz=80, project=85, extra=5, total=170
Olivia: quiz=90, project=95, extra=2, total=187

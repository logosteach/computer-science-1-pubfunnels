Lesson 002 - Defining and Calling Functions: Talking Points & Discussion

Key talking points and discussion questions to help guide your teaching of this lesson.

Main Talking Points

  • The def keyword: Starts a function definition. Indent the body under the header just like with loops and conditionals.

  • Define vs call: Defining stores instructions; calling with function_name() actually runs them.

  • Parentheses matter: greet refers to the function object; greet() executes it.

  • Order in a file: Define a function before you call it (top-to-bottom reading order).

  • Simple output functions: Great first practice — functions that print menus, messages, or separators.

Discussion & Thought Questions

  • What happens if you define a function but never call it?

  • What is the difference between say_hello and say_hello()?

  • Why must function bodies be indented?

  • How would you design a function that displays a daily checklist for a student?

  • How does “calling” a function relate to the idea that God calls people by name for a purpose?

Biblical Integration

Just as God calls us by name and gives us purpose, we call functions so they perform the specific tasks for which they were written. Purpose and action go together.

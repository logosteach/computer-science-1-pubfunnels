Lesson 003 - Function Parameters and Arguments: Talking Points & Discussion

Key talking points and discussion questions to help guide your teaching of this lesson.

Main Talking Points

  • Parameter vs argument: Parameters are placeholders in the definition; arguments are the real values supplied at the call.

  • Positional arguments: Matched by order. Easy to misuse if values are swapped.

  • Keyword arguments: Named at the call site for clarity and flexible order.

  • Default values: Provide a fallback when a caller omits an argument. Put defaults after required parameters.

  • Clear communication: Good parameter design makes a function’s expectations obvious — like clear instructions.

Discussion & Thought Questions

  • In your own words, what is the difference between a parameter and an argument?

  • When would keyword arguments be safer than positional arguments?

  • Why should parameters with defaults come after required parameters?

  • Design a function for a school event. What parameters would you include, and which would have defaults?

  • How does clear communication in Scripture parallel clear parameters in a function?

Lesson Examples - Division in Python

These examples distinguish Python’s three division-related operators: / (true division), // (floor division), and % (remainder).

Three Operators: /, //, and %

Each answers a different question: exact quotient, whole groups, or leftover.

Example 
print(17 / 5)   # true (float) division
print(17 // 5)  # floor division
print(17 % 5)   # remainder (modulo)

Output:

3.4
3
2

True Division with /

Always produces a float in Python 3, even when dividing integers evenly.

Example 
print(10 / 2)
print(type(10 / 2))
print(9 / 2)

Output:

5.0
<class 'float'>
4.5

Floor Division and Modulo

// gives how many whole times; % gives what is left over.

Example 
cookies = 17
people = 5
each = cookies // people
left = cookies % people
print(f"Each person: {each}")
print(f"Left over: {left}")
# Check: each * people + left == cookies
print(each * people + left)

Output:

Each person: 3
Left over: 2
17
Tip: For positive numbers: n == (n // d) * d + (n % d).

Predict the Output

Practice reading expressions before running them.

Example 
print(20 / 6)
print(20 // 6)
print(20 % 6)
print(7 // 2, 7 % 2)
print(8 / 4, 8 // 4, 8 % 4)

Output:

3.3333333333333335
3
2
3 1
2.0 2 0

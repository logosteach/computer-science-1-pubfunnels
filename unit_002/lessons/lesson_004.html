Lesson Examples - Printing and Escape Characters

These examples show how to use print() with multiple arguments and how escape characters control layout in console output.

print() with Multiple Arguments

print can take several values. By default they are separated by a space.

Example 
name = "Noah"
score = 95
print("Student:", name, "Score:", score)
print("A", "B", "C", sep="-")
print("Line", end=" ")
print("continues")

Output:

Student: Noah Score: 95
A-B-C
Line continues

Escape Characters

A backslash starts an escape sequence inside a string.

Example 
print("First line\nSecond line")
print("Name:\tEli")
print("Path: C:\\Users\\camper")
print("She said, \"Welcome!\"")

Output:

First line
Second line
Name:	Eli
Path: C:\Users\camper
She said, "Welcome!"

Readable Console Layout

Combine print features for clean output students can scan quickly.

Example 
print("Camp Roster")
print("=" * 20)
print("1.\tRuth\tCabin A")
print("2.\tBoaz\tCabin B")
print("=" * 20)

Output:

Camp Roster
====================
1.	Ruth	Cabin A
2.	Boaz	Cabin B
====================

Common Escape Sequences

Memorize the set you will use most often: newline, tab, backslash, and quote.

Example 
print("Use \\n for a new line.")
print("Use \\t for a tab.")
print("Use \\\\ for a backslash.")
print("Use \\\" for a quote inside double quotes.")

Output:

Use \n for a new line.
Use \t for a tab.
Use \\ for a backslash.
Use \" for a quote inside double quotes.
Tip: If a string is messy with escapes, keep practicing \n and \t deliberately—control of output is a real skill.

Lesson Examples - int(), float() and str() Functions

These examples focus on converting values with int(), float(), and str(), including common cases and errors when types do not match.

Converting with int(), float(), str()

Each function returns a new value of the requested type (when conversion is valid).

Example 
print(int(3.9))       # truncates toward zero
print(float(7))
print(str(3.14))
print(int("25") + 5)
print(float("2.5") * 2)

Output:

3
7.0
3.14
30
5.0

When Conversion Is Necessary

User input and many file values arrive as strings. Math requires numbers.

Example 
raw = "12"          # imagine this came from input()
# print(raw + 3)    # TypeError
n = int(raw)
print(n + 3)

Output:

15
Watch out: You cannot add a str and an int without converting first.

Safe Patterns for Numeric Input

Convert immediately after you receive a string that should be numeric.

Example 
# Simulated input (no keyboard needed for this example)
age_text = "16"
price_text = "9.99"
age = int(age_text)
price = float(price_text)
print(f"Age next year: {age + 1}")
print(f"Two items: ${price * 2:.2f}")

Output:

Age next year: 17
Two items: $19.98

Common Conversion Errors

Invalid text cannot become a number.

Example 
print(int("42"))
# print(int("42.5"))   # ValueError
print(float("42.5"))
print(int(float("42.5")))  # convert in steps
# print(int("hello"))  # ValueError

Output:

42
42.5
42
Tip: If a string has a decimal point, use float() first (or validate the text).

Lesson Examples - Data Types and Type Conversion

These examples introduce Python’s main basic data types, how to check them with type(), and how to convert between them when needed.

Main Data Types: int, float, str, bool

Different kinds of values are stored as different types.

Example 
count = 7           # int
price = 3.50        # float
label = "camper"    # str
active = True       # bool

print(count, price, label, active)

Output:

7 3.5 camper True

Checking Types with type()

Use type() to see how Python classifies a value.

Example 
print(type(7))
print(type(3.5))
print(type("7"))
print(type(True))
print(type(7) == int)

Output:

<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
True
Tip: "7" is a string, not a number. Quotes change the type.

Why Types Matter

Operations depend on type. Adding numbers and “adding” strings are different.

Example 
print(2 + 3)          # arithmetic
print("2" + "3")      # concatenation
# print(2 + "3")      # TypeError if uncommented

Output:

5
23
Watch out: Mixing incompatible types often raises TypeError.

Converting Between Types

Use int(), float(), str(), and bool() when a conversion is needed.

Example 
text_number = "42"
n = int(text_number)
print(n + 8)

print(float("3.14"))
print(str(100))
print(bool(0), bool(1), bool(""))

Output:

50
3.14
100
False True False

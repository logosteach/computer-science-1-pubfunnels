Lesson Examples - Order of Operations in Python

These examples show how Python evaluates arithmetic using operator precedence (PEMDAS), how parentheses change the result, and common mistakes to avoid.

PEMDAS / Operator Precedence

Python does not always evaluate left to right. Multiplication and division happen before addition and subtraction. Exponentiation is even higher. Parentheses force the order you want.

Example 
print(2 + 3 * 4)      # multiplication first
print((2 + 3) * 4)    # parentheses first
print(10 - 4 + 2)     # left to right for same level
print(2 ** 3 ** 2)    # exponentiation is right-associative
print((2 ** 3) ** 2)

Output:

14
20
8
512
64
Tip: Remember PEMDAS: Parentheses, Exponents, Multiplication/Division (left to right), Addition/Subtraction (left to right).

Using Parentheses to Control Order

When in doubt, use parentheses. They make your intent clear to Python and to human readers.

Example 
# Average of three scores — need parentheses!
score1, score2, score3 = 80, 90, 100
wrong = score1 + score2 + score3 / 3
right = (score1 + score2 + score3) / 3
print("Without parentheses:", wrong)
print("With parentheses:", right)

Output:

Without parentheses: 203.33333333333334
With parentheses: 90.0
Watch out: Forgetting parentheses around a sum before dividing is a classic bug.

Complex Expressions

Combine operations carefully and check intermediate reasoning.

Example 
result = 5 + 2 * 3 ** 2 - 8 / 4
print(result)
# Steps: 3**2=9 → 2*9=18 → 8/4=2.0 → 5+18-2.0 = 21.0

result2 = (5 + 2) * (3 ** 2 - 8) / 4
print(result2)

Output:

21.0
1.75

Common Precedence Mistakes

Watch for mixing integer thinking with floats, and for assuming every operator has equal priority.

Example 
print(1 + 2 * 3)     # not 9
print(10 / 2 * 5)    # left to right: (10/2)*5
print(10 / (2 * 5))  # different result
print(2 ** 3 * 2)    # (2**3)*2 = 16, not 2**(3*2)

Output:

7
25.0
1.0
16

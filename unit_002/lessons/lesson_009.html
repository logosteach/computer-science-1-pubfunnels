Lesson Examples - More About Strings

These examples show how to slice strings, why strings are immutable, and what happens if you try to change a character in place.

Slicing with [start:end:step]

Slicing extracts a portion of a string. end is exclusive. step can skip characters or reverse.

Example 
text = "LogosTeach"
print(text[0:5])     # characters at indexes 0-4
print(text[5:])      # from index 5 to the end
print(text[:5])      # start through index 4
print(text[::2])     # every other character
print(text[::-1])    # reversed

Output:

Logos
Teach
Logos
Lgsec
hcaeTsogoL
Tip: Indexing starts at 0. Slice [a:b] includes a and excludes b.

String Immutability

Strings cannot be changed in place. Methods and slices return new strings.

Example 
word = "hello"
print(word.upper())  # new string
print(word)          # original unchanged

# word[0] = "H"     # TypeError if uncommented
word = "H" + word[1:]
print(word)

Output:

HELLO
hello
Hello

Attempting Direct Modification

Assignment to an index on a string fails.

Example 
s = "cat"
try:
    s[0] = "b"
except TypeError as e:
    print("Error:", e)

Output:

Error: 'str' object does not support item assignment
Watch out: To “change” text, build a new string and reassign the variable.

Practical Slicing

Extract useful pieces: first name, last name, or last characters.

Example 
full = "John Partridge"
first = full[:4]
last = full[5:]
print(first)
print(last)
print(full[-9:])  # last 9 characters

Output:

John
Partridge
Partridge

Lesson 002 - Variables — Talking Points

Key talking points and discussion notes for teaching declaring and assigning variables, naming rules, reassignment, and using variables in expressions.

Main Teaching Points

  • Assignment with =: Creates or updates a name that refers to a value. Not the same as mathematical equality.

  • Naming rules: Start with letter/underscore; snake_case; case-sensitive; no keywords.

  • Reassignment: The same name can refer to a new value; emphasize tracing values step by step.

  • Use in expressions: Build formulas with names, not magic numbers.

  • Contrast with God’s promises: Mutable variables vs. immutable promises (2 Cor 1:20)—clear contrast, not confusion.

Discussion & Talking Points

  • Question 1: What is the difference between = in Python and = in algebra?

  • Question 2: Which of these are valid names: score2, 2score, my-score, my_score?

  • Question 3: What prints after: x = 5; x = x + 1; print(x)?

  • Question 4: Why are descriptive variable names a kindness to future readers (including you)?

  • Question 5: How do changeable variables help us appreciate that God’s promises never change?

Biblical Integration

Variables in Python can change value at any time. God’s promises in Christ do not. They are Yes and Amen—a foundation that does not shift.

Scripture (NKJV):
“For all the promises of God in Him are Yes, and in Him Amen, to the glory of God through us.” (2 Corinthians 1:20, NKJV)

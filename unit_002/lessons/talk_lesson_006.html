Lesson 006 - Division in Python — Talking Points

Key talking points and discussion notes for teaching true division /, floor division //, and modulo % with real-world examples.

Main Teaching Points

  • Three questions: / exact quotient, // whole groups, % leftover.

  • / always float in Py3: 10/2 is 5.0 not 5.

  • Identity check: n == (n//d)*d + (n%d) for positive ints.

  • Real problems: Splitting teams, change-making, even/odd with % 2.

  • 2 Tim 2:15: Careful handling—connect thoughtfully.

Discussion & Talking Points

  • Question 1: What is the difference between 17/5 and 17//5?

  • Question 2: How do you test whether a number is even using %?

  • Question 3: If 50 stickers are shared among 8 students, how many each and how many left?

  • Question 4: Why is 10/2 a float?

  • Question 5: How does carefully choosing an operator parallel carefully handling Scripture?

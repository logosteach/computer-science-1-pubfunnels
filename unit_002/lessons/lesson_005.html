Lesson Examples - F-Strings

These examples show why f-strings are preferred for readable dynamic text, how to embed variables and expressions, and simple number formatting.

Why F-Strings?

F-strings (formatted string literals) embed values directly inside a string with curly braces. They are usually clearer than older + concatenation or % formatting.

Example 
name = "Maria"
score = 88
# Older style
print("Hello, " + name + "! Score: " + str(score))
# F-string
print(f"Hello, {name}! Score: {score}")

Output:

Hello, Maria! Score: 88
Hello, Maria! Score: 88
Tip: Put an f before the opening quote: f"...".

Embedding Variables and Expressions

Anything inside {} is evaluated and inserted as text.

Example 
a = 10
b = 4
print(f"{a} + {b} = {a + b}")
print(f"Next year age: {15 + 1}")

Output:

10 + 4 = 14
Next year age: 16

Formatting Numbers

Use format specs after a colon for decimals, padding, and percentages.

Example 
price = 19.5
ratio = 2 / 3
print(f"Price: ${price:.2f}")
print(f"Ratio: {ratio:.3f}")
print(f"Percent: {ratio:.1%}")
print(f"Num: {42:05d}")

Output:

Price: $19.50
Ratio: 0.667
Percent: 66.7%
Num: 00042

Readable Dynamic Output

F-strings keep labels and values together so reports stay easy to read.

Example 
camper = "Silas"
cabin = "B"
nights = 5
print(f"{camper} is in cabin {cabin} for {nights} nights.")
print(f"Total cost: ${nights * 45:.2f}")

Output:

Silas is in cabin B for 5 nights.
Total cost: $225.00

Lesson Examples - The input() Function

These examples show how input() reads text from the user, how to store and convert that text, and how to build simple interactive programs with print().

Getting Data with input()

input() pauses and reads a line of text from the user. It always returns a string.

Example 
# For demos without a keyboard, we simulate input results:
# name = input("What is your name? ")
name = "Ava"  # simulated
print("Hello,", name)
print(type(name))

Output:

Hello, Ava
<class 'str'>
Tip: In real programs use input("prompt: "). Here values are simulated so examples run offline.

Store and Process Input

Save the result in a variable, then use it in messages and logic.

Example 
# color = input("Favorite color? ")
color = "blue"  # simulated
message = f"Your favorite color is {color}."
print(message)
print(color.upper())

Output:

Your favorite color is blue.
BLUE

Convert Input to Numbers

Because input is a string, convert before arithmetic.

Example 
# age_text = input("Age: ")
age_text = "14"  # simulated
age = int(age_text)
print(f"Next year you will be {age + 1}.")

# price_text = input("Price: ")
price_text = "3.50"
price = float(price_text)
print(f"Two cost ${price * 2:.2f}")

Output:

Next year you will be 15.
Two cost $7.00
Watch out: int(input(...)) fails if the user types non-numeric text—validate later as skills grow.

Simple Interactive Program Pattern

Prompt → convert if needed → process → print results.

Example 
# Simulated interactive session
# name = input("Name: ")
# qty_text = input("How many stickers? ")
name = "Micah"
qty_text = "7"
qty = int(qty_text)
print(f"{name} ordered {qty} stickers.")
print(f"Total: ${qty * 0.25:.2f}")

Output:

Micah ordered 7 stickers.
Total: $1.75

Lesson Examples - Variables

These examples show how to create variables, follow naming rules, reassign values, and use variables in math and output.

Declaring and Assigning Variables

A variable is a name that refers to a value. Use a single equals sign (=) to assign.

Example 
name = "Hannah"
age = 15
score = 92.5
is_student = True

print(name)
print(age)
print(score)
print(is_student)

Output:

Hannah
15
92.5
True

Naming Rules and Best Practices

Names must start with a letter or underscore, can contain letters, digits, and underscores, and are case-sensitive. Prefer descriptive snake_case names.

Example 
# Good names
first_name = "Eli"
quiz_score = 88
_total = 100

# Case-sensitive
Score = 90
score = 80
print(Score, score)

# Invalid (do not run): 2score = 10  or  first-name = "x"

Output:

90 80
Tip: Avoid single-letter names except for short loops. Never use Python keywords (if, for, class, etc.) as names.

Reassignment (Values Can Change)

You can assign a new value to the same variable. The name now points to the new value.

Example 
points = 10
print("Start:", points)
points = points + 5
print("After bonus:", points)
points = 100
print("Reset:", points)

Output:

Start: 10
After bonus: 15
Reset: 100

Variables in Expressions and Output

Use variables anywhere you would use a literal value.

Example 
width = 8
height = 5
area = width * height
print("Area:", area)
print(width, "x", height, "=", area)

Output:

Area: 40
8 x 5 = 40

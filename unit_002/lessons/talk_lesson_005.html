Lesson 005 - F-Strings — Talking Points

Key talking points and discussion notes for teaching embedding variables and expressions in strings with f-strings and basic formatting options.

Main Teaching Points

  • f prefix + {}: Syntax and why it beats messy concatenation.

  • Expressions inside braces: Not only variables—small calculations are fine.

  • Format specs: .2f, padding, % — practical for money and reports.

  • Readability goal: Output should be clear for teachers, parents, and teammates.

  • Visibility analogy: Christ made known / treasures of wisdom—handle gently.

Discussion & Talking Points

  • Question 1: What is missing if you write "{name}" without the f prefix?

  • Question 2: Rewrite a + concatenation message as an f-string.

  • Question 3: How do you show a float with exactly two decimal places?

  • Question 4: When might an expression inside {} be better than a temporary variable?

  • Question 5: How does making a value “visible” in a string help us talk about knowing Christ more clearly?

Biblical Integration

F-strings make values visible inside a message. Applying the teachings of Christ makes Him more visible in our lives—what was hidden grows clearer as we know Him.

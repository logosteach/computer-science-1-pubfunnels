Lesson 002 - Python Lists — Talking Points

Key talking points and discussion notes for teaching Python lists: creating lists, indexing, modifying and growing collections, built-in functions, and for loops over list items.

Main Teaching Points

  • What a list is: An ordered, mutable collection written with square brackets. Can hold strings, numbers, or mixed types. Empty list: [].

  • Indexing: Positions start at 0. Negative indexes count from the end (-1 is last). Out-of-range access raises IndexError.

  • Modify in place: Assign to an index to change a value. Lists are mutable—they can change after creation.

  • Adding and removing: append(item) adds at the end; insert(index, item) places at a position; remove(value) deletes the first matching value (raises ValueError if missing).

  • Built-in helpers: len() for count; for numeric lists, min(), max(), and sum(). Average often uses sum(list) / len(list).

  • Iterate with for: for item in my_list: visits each element in order—the standard way to process every value.

  • Clear names help: Prefer plural list names (scores, campers) and singular loop variables (for score in scores).

Discussion & Talking Points

  • Question 1: Why does Python number list positions from zero instead of one? How does that affect the last valid index for a list of length 5?

  • Question 2: When would you use append() vs insert()? Give a classroom or camp roster example.

  • Question 3: What is the difference between changing scores[0] = 100 and creating a brand-new list?

  • Question 4: Why might sum() fail on a list of strings? What assumption do min/max/sum make?

  • Question 5: How does a list gathering many items into one collection help us picture God gathering people into communities where each person has value and purpose?

Biblical Integration

Lists organize many items into one collection, and each item still has its place. God gathers His people into communities and families—not as spare parts, but as members who belong and serve together under Christ.

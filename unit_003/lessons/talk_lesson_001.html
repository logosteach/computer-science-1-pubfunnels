Lesson 001 - Modules and Import Statements — Talking Points

Key talking points and discussion notes for teaching modules and import statements: what modules are, why they matter, import vs from ... import ..., and the value of building on others’ work.

Main Teaching Points

  • What a module is: A module is a Python file (.py) that groups related code—functions, constants, or tools—you can reuse. Importing makes that code available without rewriting it.

  • Why modules are useful: Reuse, organization, building on the standard library and community packages, and avoiding reinventing common tools (math, random, dates, and more).

  • import module: Brings in the whole module. You call items with dot notation (math.sqrt(9)). Clear source of each name; fewer name clashes.

  • from module import name: Brings in specific names only. You call them directly (sqrt(9)). Shorter, but the origin is less obvious at each use.

  • Compare the two styles: Same underlying tools, different call style and clarity. Prefer whole-module import when you use many items; prefer selective import when you need only a few names.

  • Avoid star imports: from module import * dumps many names into your file and makes origin hard to track. Teach students not to use it.

  • Standard library first: Many powerful modules ship with Python—no install needed—only import.

Discussion & Talking Points

  • Question 1: Why is it wise to reuse a well-tested module instead of writing everything from scratch?

  • Question 2: Show import math vs from math import sqrt side by side. Which style is clearer for a beginner reading someone else’s code?

  • Question 3: What problems can arise if two modules both define a function with the same name and you use star imports?

  • Question 4: Can you name tools you already use that are “modules” in daily life—recipes, hymnals, study guides written by others?

  • Question 5: How does receiving gifts from other believers (teachers, song writers, servants) parallel using modules others have written for the good of the whole body?

Biblical Integration

Modules show the value of community and shared gifts. We do not build alone. God has given different people different abilities for the common good—just as different modules contribute different strengths to a program.

But the manifestation of the Spirit is given to each one for the profit of all.” (1 Corinthians 12:4–7)

Lesson Examples - Python Dictionaries

These examples show how to create dictionaries (key–value pairs), access and update items, loop through keys / values / items, and use methods such as get(), keys(), values(), items(), and update().

Creating Dictionaries

A dictionary stores data as key → value pairs. Keys must be unique and immutable (strings and numbers are common). Values can be almost any type.

Empty dict and a dictionary with pairs 
empty = {}
student = {
    "name": "Silas",
    "age": 16,
    "course": "Python"
}

print(student)
print(type(empty))

Output:

{'name': 'Silas', 'age': 16, 'course': 'Python'}
<class 'dict'>
Tip: Think of a phone book: you look up a name (key) to find a number (value)—not “the third entry on the page.”

Access, Add, Modify, and Remove

Read, write, and delete by key 
camper = {"name": "Ruth", "cabin": "A", "grade": 10}

print(camper["name"])       # access
camper["grade"] = 11        # modify
camper["activity"] = "choir"  # add new key
del camper["cabin"]         # remove a key

print(camper)

Output:

Ruth
{'name': 'Ruth', 'grade': 11, 'activity': 'choir'}
Watch out: Accessing a missing key with square brackets raises KeyError. Prefer get() when the key might not exist.

Methods: get(), keys(), values(), items(), update()

get() with a default 
scores = {"math": 92, "science": 88}

print(scores.get("math"))
print(scores.get("history"))            # None if missing
print(scores.get("history", "N/A"))     # custom default

Output:

92
None
N/A
keys, values, items, and update 
info = {"name": "Leah", "role": "student"}

print(list(info.keys()))
print(list(info.values()))
print(list(info.items()))

info.update({"role": "mentor", "years": 2})
print(info)

Output:

['name', 'role']
['Leah', 'student']
[('name', 'Leah'), ('role', 'student')]
{'name': 'Leah', 'role': 'mentor', 'years': 2}

Iterating Through a Dictionary

You can loop over keys only, values only, or key–value pairs with .items().

Three common loop styles 
ministry = {
    "prayer": 12,
    "worship": 8,
    "service": 15
}

print("--- keys ---")
for key in ministry:
    print(key)

print("--- values ---")
for count in ministry.values():
    print(count)

print("--- items ---")
for area, count in ministry.items():
    print(area, "→", count, "students")

Output:

--- keys ---
prayer
worship
service
--- values ---
12
8
15
--- items ---
prayer → 12 students
worship → 8 students
service → 15 students

When a Dictionary Is the Best Choice

Use a dictionary when you look up data by a meaningful label (name, id, product code) rather than by position. Lists are great for ordered sequences; dictionaries shine for labeled records and fast lookup by key.

List vs dictionary for the same person 
# List: remember that index 0 is name, 1 is score...
student_list = ["Alice", 85, "Math"]

# Dictionary: labels make the meaning clear
student_dict = {"name": "Alice", "score": 85, "subject": "Math"}

print(student_list[1])
print(student_dict["score"])

Output:

85
85

Putting It Together

Simple camper record 
camper = {}
camper["name"] = "Micah"
camper["cabin"] = "B"
camper.update({"allergies": "none", "age": 14})

print(camper.get("name"), "is in cabin", camper.get("cabin"))

for key, value in camper.items():
    print(f"  {key}: {value}")

if "allergies" in camper:
    print("Allergy note on file.")

Output:

Micah is in cabin B
  name: Micah
  cabin: B
  allergies: none
  age: 14
Allergy note on file.

Lesson Examples - Python Tuples

These examples show how to create tuples, how they differ from lists (immutability), when a tuple is the better choice, and how to unpack fixed collections of data.

Creating Tuples

A tuple is an ordered collection written with parentheses. Items are separated by commas. A one-item tuple needs a trailing comma so Python does not treat it as a plain value in parentheses.

Empty, single-item, and multi-item tuples 
empty = ()
point = (3, 5)
rgb = (255, 128, 0)
single = (42,)          # trailing comma required
also_a_tuple = 10, 20   # parentheses optional when packing

print(point)
print(single)
print(type(single))
print(also_a_tuple)

Output:

(3, 5)
(42,)
<class 'tuple'>
(10, 20)
Watch out: (42) is just the integer 42. (42,) is a one-element tuple. The comma is what makes it a tuple.

Indexing and Length

Like lists, tuples use zero-based indexes and support len() and negative indexes.

Read values by index 
card = ("Ace", "Spades")
print(card[0])
print(card[1])
print(card[-1])
print(len(card))

Output:

Ace
Spades
Spades
2

Tuples Are Immutable (Unlike Lists)

After a tuple is created, you cannot change, add, or remove its elements. That is the key difference from a list.

Lists can change; tuples cannot 
scores_list = [88, 92, 75]
scores_list[0] = 90          # OK for a list
print(scores_list)

scores_tuple = (88, 92, 75)
# scores_tuple[0] = 90       # TypeError if uncommented
print(scores_tuple)

Output:

[90, 92, 75]
(88, 92, 75)
Watch out: Trying to assign to a tuple index raises TypeError: 'tuple' object does not support item assignment.

When to Use a Tuple Instead of a List

Choose a tuple when the collection should stay fixed: coordinates, RGB colors, days of the week as a fixed sequence, or a small record of related values that should not be edited later. Choose a list when you expect to append, remove, or reorder items.

Fixed data fits a tuple well 
# Fixed pair: latitude and longitude should not be reordered by accident
camp_location = (45.5231, -122.6765)

# Fixed triple: red, green, blue
logo_color = (44, 122, 123)

print("Lat:", camp_location[0], "Lon:", camp_location[1])
print("RGB:", logo_color)

Output:

Lat: 45.5231 Lon: -122.6765
RGB: (44, 122, 123)
Tip: Immutability is a feature, not a limitation. It protects data that should remain stable and makes your intent clearer to readers of your code.

Unpacking Tuples

Unpacking assigns each item in a tuple to its own variable in one step. The number of variables must match the number of items (unless you use advanced patterns later).

Basic unpacking 
student = ("Hannah", 15, "Python")
name, age, course = student

print(name)
print(age)
print(course)

Output:

Hannah
15
Python
Swap two variables with unpacking 
a = "first"
b = "second"
a, b = b, a
print(a)
print(b)

Output:

second
first
Loop over a list of tuples 
roster = [
    ("Eli", "Cabin A"),
    ("Maria", "Cabin B"),
    ("Noah", "Cabin A"),
]

for name, cabin in roster:
    print(name, "→", cabin)

Output:

Eli → Cabin A
Maria → Cabin B
Noah → Cabin A

Putting It Together

Fixed week schedule as tuples 
schedule = (
    ("Monday", "Lists review"),
    ("Tuesday", "Sets lab"),
    ("Wednesday", "Tuples intro"),
)

for day, topic in schedule:
    print(f"{day}: {topic}")

print("Days planned:", len(schedule))
# schedule[0] = ("Monday", "Something else")  # would raise TypeError

Output:

Monday: Lists review
Tuesday: Sets lab
Wednesday: Tuples intro
Days planned: 3

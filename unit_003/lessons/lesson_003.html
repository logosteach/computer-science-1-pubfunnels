Lesson Examples - Python Sets

These examples show how to create sets, how they store only unique values, how to run union / intersection / difference operations, and how to use sets for fast membership checks and duplicate removal.

Creating Sets

A set holds unique items. Write a set with curly braces {}, or build one with set(). Use set() (not {}) for an empty set—empty curly braces create a dictionary.

Literal set and set() constructor 
gifts = {"teaching", "encouragement", "service"}
numbers = set([1, 2, 2, 3, 3, 3])
empty = set()

print(gifts)
print(numbers)
print(type(empty))

Sample output (order of set items may vary):

{'teaching', 'encouragement', 'service'}
{1, 2, 3}
<class 'set'>
Tip: Sets are unordered. Do not rely on left-to-right position the way you do with lists. If you need a stable display order, wrap the set in sorted().

Unique Elements (Duplicates Removed)

If the same value appears more than once when you build a set, Python keeps only one copy.

Duplicates disappear automatically 
attendees = {"Anna", "Ben", "Anna", "Caleb", "Ben"}
print(attendees)
print(len(attendees))

Sample output:

{'Anna', 'Ben', 'Caleb'}
3

Union, Intersection, Difference, Symmetric Difference

Set operations compare two collections. Operators and method names both work.

Common set operations 
group_a = {"Ruth", "Naomi", "Boaz"}
group_b = {"Boaz", "David", "Ruth"}

print("Union:", group_a | group_b)
print("Intersection:", group_a & group_b)
print("Difference A-B:", group_a - group_b)
print("Symmetric difference:", group_a ^ group_b)

# Same ideas with methods:
print(group_a.union(group_b))
print(group_a.intersection(group_b))
print(group_a.difference(group_b))
print(group_a.symmetric_difference(group_b))

Meaning in plain language:

  • Union — everyone in either group
  • Intersection — only people in both groups
  • Difference — in the first group but not the second
  • Symmetric difference — in one group or the other, but not both

Membership Testing and Removing Duplicates

The in operator is fast on sets. Converting a list to a set (and back, if needed) is a common way to drop duplicates.

Membership with in 
verse_refs = {"John 3:16", "Romans 8:28", "Psalm 23:1"}

print("Romans 8:28" in verse_refs)
print("Genesis 1:1" in verse_refs)

Output:

True
False
Remove duplicates from a list 
raw_names = ["Eli", "Maria", "Eli", "Noah", "Maria", "Ava"]
unique_names = list(set(raw_names))
print(sorted(unique_names))  # sorted for a stable display order

Output:

['Ava', 'Eli', 'Maria', 'Noah']
add() and discard() 
topics = {"prayer", "worship"}
topics.add("service")
topics.discard("worship")
print(sorted(topics))

Output:

['prayer', 'service']
Watch out: remove() raises a KeyError if the item is missing. discard() does nothing if the item is not in the set—safer when you are unsure.

Putting It Together

Find shared and unique camp activities 
cabin_1 = {"hiking", "crafts", "swimming"}
cabin_2 = {"swimming", "archery", "crafts"}

shared = cabin_1 & cabin_2
only_cabin_1 = cabin_1 - cabin_2
all_activities = cabin_1 | cabin_2

print("Shared:", sorted(shared))
print("Only cabin 1:", sorted(only_cabin_1))
print("All unique:", sorted(all_activities))
print("Count of unique activities:", len(all_activities))

Output:

Shared: ['crafts', 'swimming']
Only cabin 1: ['hiking']
All unique: ['archery', 'crafts', 'hiking', 'swimming']
Count of unique activities: 4

Lesson Examples - Python Lists

These examples show how to create lists, access and change their elements, use helpful built-in functions, and walk through a list with a for loop. Lists let you store an ordered collection of items in one variable—names, scores, tasks, or anything else you need to organize.

Creating Lists

A list is written with square brackets. Items are separated by commas. Lists can hold strings, numbers, or a mix of types. You can also start with an empty list and fill it later.

Empty list and lists with values 
empty_list = []
campers = ["Maria", "Eli", "Noah", "Ava"]
scores = [88, 92, 75, 100]
mixed = ["Unit 3", 3, True]

print(campers)
print(scores)

Output:

['Maria', 'Eli', 'Noah', 'Ava']
[88, 92, 75, 100]
Tip: Choose a clear, plural variable name when a list holds many related items (for example, campers or scores). That makes your intent easy to read.

Accessing Elements with Indexing

List positions start at 0. Use square brackets to read one item. Negative indexes count from the end: -1 is the last item.

Positive and negative indexes 
fruits = ["apple", "banana", "cherry", "date"]

print(fruits[0])    # first item
print(fruits[2])    # third item
print(fruits[-1])   # last item
print(fruits[-2])   # second-to-last item

Output:

apple
cherry
date
cherry
Watch out: Using an index that does not exist raises an IndexError. For a list of length 4, valid indexes are 0 through 3 (and -1 through -4).

Modifying, Adding, and Removing Elements

Lists are mutable: you can change them after they are created. Assign a new value at an index, add with append() or insert(), and take items out with remove().

Change an element by index 
tasks = ["read", "practice", "review"]
tasks[1] = "code lab"
print(tasks)

Output:

['read', 'code lab', 'review']
append() adds to the end; insert() places at an index 
guests = ["Anna", "Ben"]
guests.append("Caleb")      # add at the end
guests.insert(1, "Debra")   # insert at index 1
print(guests)

Output:

['Anna', 'Debra', 'Ben', 'Caleb']
remove() deletes the first matching value 
supplies = ["Bible", "notebook", "pen", "notebook"]
supplies.remove("notebook")
print(supplies)

Output:

['Bible', 'pen', 'notebook']
Tip: append(item) always goes at the end. insert(index, item) puts the item at that position and shifts later items right. remove(value) looks for the value, not the index—and only removes the first match.
Watch out: If the value is not in the list, remove() raises a ValueError. Check with in first when the item might be missing.

Built-in Functions: len(), min(), max(), sum()

Python provides functions that work with lists without writing a loop yourself. Use len() for how many items; for numeric lists, min(), max(), and sum() find the smallest, largest, and total.

Length of any list 
team = ["Grace", "Isaac", "Leah", "Paul"]
print(len(team))

Output:

4
min, max, and sum with numbers 
quiz_scores = [78, 91, 85, 100, 88]

print(min(quiz_scores))
print(max(quiz_scores))
print(sum(quiz_scores))
print(sum(quiz_scores) / len(quiz_scores))  # average

Output:

78
100
442
88.4
Tip: min(), max(), and sum() work best when every item is a number. Mixing strings and numbers will usually cause a TypeError.

Iterating with a for Loop

A for loop visits each element in order. The loop variable holds the current item for that pass. This is the most common way to process every value in a list.

Print each item 
names = ["Ruth", "Boaz", "Naomi"]

for name in names:
    print(name)

Output:

Ruth
Boaz
Naomi
Use each item in a calculation 
points = [10, 15, 20]
total = 0

for score in points:
    total = total + score

print("Total points:", total)

Output:

Total points: 45
Combine a loop with a condition 
temperatures = [68, 72, 81, 65, 90]

for temp in temperatures:
    if temp >= 80:
        print(temp, "is warm")
    else:
        print(temp, "is mild")

Output:

68 is mild
72 is mild
81 is warm
65 is mild
90 is warm
Tip: Name the loop variable after a single item (for name in names, not for names in names. Clear names make the loop easier to understand.

Putting It Together

This short program creates a list, updates it with methods, reports statistics, and prints each student.

A small class roster program 
students = ["Hannah", "Micah"]
students.append("Silas")
students.insert(0, "Esther")
students.remove("Micah")

print("Roster:", students)
print("Count:", len(students))

for student in students:
    print("Welcome,", student + "!")

Output:

Roster: ['Esther', 'Hannah', 'Silas']
Count: 3
Welcome, Esther!
Welcome, Hannah!
Welcome, Silas!

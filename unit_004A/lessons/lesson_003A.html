Lesson 003A - Logical Operators: and, or, not and Compound Conditions

These examples demonstrate how to combine multiple conditions using Python's logical operators and, or, and not. You will learn to create compound conditional expressions, understand operator precedence, and write more powerful, realistic decision logic in your programs.

Example 1: Combining Conditions with 'and'

The and operator requires both conditions to be True for the overall expression to be true. This is useful when multiple requirements must be met simultaneously.

age = 20
is_student = True

if age < 25 and is_student:
    print("You qualify for the student discount!")
else:
    print("Sorry, no discount available.")

Output:

You qualify for the student discount!
The and operator uses short-circuit evaluation: if the left condition is False, Python does not evaluate the right condition.

Example 2: Using 'or' for Alternative Conditions

The or operator returns True if at least one of the conditions is true. It is ideal for situations with multiple acceptable paths.

is_weekend = False
is_holiday = True

if is_weekend or is_holiday:
    print("Enjoy your day off!")
else:
    print("Time to work or study.")

Output:

Enjoy your day off!

Example 3: Using 'not' to Negate a Condition

The not operator inverts the boolean value of a condition. It is powerful for expressing "if something is NOT the case."

is_sunny = True

if not is_sunny:
    print("Bring an umbrella or stay indoors.")
else:
    print("Perfect weather for outdoor plans!")

Output:

Perfect weather for outdoor plans!
Overusing not can make code harder to read. Prefer positive conditions when possible, or use clear variable names like is_raining instead of not is_sunny.

Example 4: Creating Compound Conditional Expressions

You can combine and, or, and not to express sophisticated logic. Always use parentheses to group conditions clearly and control evaluation order.

height_cm = 150
has_adult_supervision = True

# Compound rule: tall enough alone OR tall enough with adult
if (height_cm >= 160) or (height_cm >= 140 and has_adult_supervision):
    print("Access granted to the ride.")
else:
    print("Sorry, height requirements not met.")

Output:

Access granted to the ride.

This pattern appears in real systems like access control, eligibility checks, and game rules where multiple criteria must be evaluated together.

Example 5: Understanding Order of Precedence

Python evaluates logical operators in this order (highest to lowest precedence):

  1. not
  2. and
  3. or

Without parentheses, expressions can produce unexpected results. Always use parentheses for clarity when mixing operators.

cloudy = True
raining = False
cold = True

# Without parens: not cloudy and raining or cold
# Evaluated as: (not cloudy) and raining or cold → False and False or True → True
if not cloudy and raining or cold:
    print("It might be a good day for hot chocolate.")
else:
    print("Weather is clear and warm.")

Output:

It might be a good day for hot chocolate.

Compare with explicit grouping to see how precedence affects logic:

# Different result with parentheses
if not (cloudy and raining) or cold:
    print("Different grouping changes the outcome.")

Example 6: Writing Powerful and Realistic Conditions

Compound logic shines in real-world scenarios like authentication, recommendation systems, or safety checks. Here is a practical example modeling a smart home security decision.

door_locked = True
motion_detected = False
alarm_armed = True
is_night = True

# Realistic compound rule for triggering alarm
if alarm_armed and (not door_locked or motion_detected) and is_night:
    print("ALERT: Possible security breach detected!")
else:
    print("All systems normal. Home is secure.")

Output:

All systems normal. Home is secure.

Notice how multiple real-world factors (door status, motion, time of day, system state) are weighed together using compound logic to reach one actionable decision.

Biblical Reflection

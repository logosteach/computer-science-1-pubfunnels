If, Elif, and Else Statements

In this lesson, you will learn how to use if, elif, and else statements to make decisions in your programs. These structures allow your code to take different paths based on conditions.

Lesson Objectives

  • Write if, elif, and else statements correctly.

    • Understand the required syntax (colon and indentation).

    • Create single and multi-way decision structures.

  • Control program flow based on different conditions.

  • Reflect on how decision structures relate to the choices we make in life.

Opening Meditation

Examples

Example 1: Basic if Statement

age = 17 if age >= 18: print("You are an adult.")

Output: (No output — condition is False)

Example 2: if and else

age = 17 if age >= 18: print("You are an adult.") else: print("You are a minor.")

Output: You are a minor.

Example 3: Multi-way Decisions with elif

score = 85 if score >= 90: print("Grade: A") elif score >= 80: print("Grade: B") elif score >= 70: print("Grade: C") else: print("Grade: F")

Output: Grade: B

Example 4: Importance of the Colon and Indentation

temperature = 75 if temperature > 80: print("It's hot outside.") # IndentationError! else: print("Comfortable temperature.")

Result: Python raises an IndentationError because the code under the if is not indented.

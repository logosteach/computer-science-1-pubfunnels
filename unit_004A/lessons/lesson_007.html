Lesson Examples - Ternary Operator

These examples demonstrate the ternary operator (`value_if_true if condition else value_if_false`) for writing concise conditional expressions. Learn when it improves readability and when a full `if-else` is better.

Basic Ternary Operator 

age = 18
status = "Adult" if age >= 18 else "Minor"
print(f"You are a {status}.")

Output:

You are a Adult.
Tip: Ternary is great for simple assignments or return values. It condenses a full if-else into one line.

Converting if-else to Ternary (and Vice Versa) 

# Full if-else
score = 85
if score >= 60:
    result = "Pass"
else:
    result = "Fail"

# Equivalent ternary (more concise)
result = "Pass" if score >= 60 else "Fail"
print(f"Result: {result}")

Output:

Result: Pass

When to Use (and Not Use) Ternary 

# Good: Simple and readable
discount = 0.1 if is_member else 0

# Avoid when complex (use full if-else instead)
# message = "Welcome back!" if user.is_logged_in and not user.is_banned and user.has_premium else "Please log in or check your subscription."
Warning: Overly complex ternaries reduce readability. Prefer full `if-else` for multi-condition or multi-line logic.

Lesson Examples - Short-Circuit Evaluation with and and or

These examples demonstrate short-circuit evaluation in Python's logical operators. No functions are used — only basic variables and input.

What is Short-Circuit Evaluation?

Python stops evaluating a compound condition as soon as the final result is known.

  • and: Stops if the first part is False.
  • or: Stops if the first part is True.
# Short-circuit with and (division by zero avoided)
x = 0
y = 10

result = (x != 0) and (y / x > 5)   # Second part never runs!
print("Result:", result)

Predicting Evaluation Order 

denominator = 0
numerator = 100

# and short-circuits safely
safe_and = (denominator != 0) and (numerator / denominator > 5)

# or short-circuits safely
safe_or = (denominator == 0) or (numerator / denominator > 5)

print("Safe AND result:", safe_and)
print("Safe OR result:", safe_or)

Try it: Change denominator to 5 and predict what happens.

Writing Safer Code 

# Example 1: Safe user input check
age_input = input("Enter your age: ")
age = int(age_input) if age_input.isdigit() else 0

can_drive = (age >= 16) and True   # Second condition only matters if age qualifies

# Example 2: Avoid index errors
my_list = [10, 20]
index = 5
safe_access = (index < len(my_list)) and (my_list[index] > 0)
print("Safe list access:", safe_access)

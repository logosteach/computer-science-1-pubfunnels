Lesson Examples - Comparator Operators

These examples help you master the six comparator operators, write conditions comparing numbers/strings/variables, predict Boolean results, and see how comparators drive decisions in code.

The Six Comparator Operators 

# ==   Equal to
# !=   Not equal to
# >    Greater than
# <    Less than
# >=   Greater than or equal to
# <=   Less than or equal to

Example 1: Comparing Numbers 

age = 15
print(age == 18)   # False
print(age != 18)   # True
print(age >= 13)   # True
print(age < 18)    # True

Prediction: These expressions evaluate to Boolean values that can drive decisions.

Example 2: Comparing Strings and Variables 

user_role = "student"
print(user_role == "student")     # True
print(user_role != "teacher")     # True

name1 = "John"
name2 = "john"
print(name1 == name2)             # False (case-sensitive)

Example 3: Using Comparators in Decisions 

score = 85
if score >= 70:
    print("Passed the exam!")
else:
    print("Needs more study.")

Comparators are the foundation of all conditional logic in Python.

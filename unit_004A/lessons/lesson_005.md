# Lesson Examples - if, elif, and else Statements

These examples help you master writing conditional statements, multi-way decisions, proper indentation and colons, and controlling program flow. They also connect to the biblical truth that our choices matter.

## Example 1: Simple if Statement

```python
# Basic decision based on a condition
age = 17

if age >= 18:
    print("You can make this decision independently.")
print("This line always runs.")
```

**Output:**  
This line always runs.

**Tip:** Remember: The colon `:` after the condition and consistent indentation (4 spaces) are essential in Python!

## Example 2: if-elif-else (Multi-way Decision)

```python
# Choosing a path - like life's decisions
path = "God's way"

if path == "God's way":
    print("Blessed is the one who walks in obedience.")
elif path == "own way":
    print("There are consequences when we go our own way.")
else:
    print("Compromise leads to unclear direction.")
```

**Output (for "God's way"):**  
Blessed is the one who walks in obedience.

## Example 3: Controlling Program Flow (Grading Example)

```python
score = 85

if score >= 90:
    grade = "A - Excellent!"
elif score >= 80:
    grade = "B - Good job!"
elif score >= 70:
    grade = "C - Room to grow."
else:
    grade = "Needs more practice."

print(f"Your grade: {grade}")
```

**Output:**  
Your grade: B - Good job!

**Warning:** Order matters! Python checks conditions from top to bottom and stops at the first True match.

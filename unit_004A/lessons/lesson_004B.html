Lesson Examples - Nested Conditional Statements

These examples demonstrate how to create and trace nested if statements (an if inside another if). We will also explore when nesting is useful versus using compound conditions, and the importance of keeping code readable.

Basic Nested if Example 

age = 18
has_license = True

if age >= 16:
    print("You are old enough to drive.")
    if has_license:
        print("You can drive legally.")
    else:
        print("You need to get your license first.")
else:
    print("You are not old enough to drive yet.")

Output:

You are old enough to drive.
You can drive legally.
Tip: Trace the flow step-by-step. The inner if only runs if the outer condition is True.

When to Use Nested vs. Compound Conditions 

# Nested version
score = 85
attendance = 90

if score >= 70:
    if attendance >= 80:
        print("Passing with good attendance.")
    else:
        print("Passing, but improve attendance.")
else:
    print("Failing.")

Alternative with compound condition (often clearer):

if score >= 70 and attendance >= 80:
    print("Passing with good attendance.")
elif score >= 70:
    print("Passing, but improve attendance.")
else:
    print("Failing.")
Tip: Use nesting for dependent, layered decisions. Use and/or for independent conditions to keep code flatter and easier to read.

Debugging Nested Conditionals

Common issues include incorrect indentation, missing colons, or logic errors in the nesting levels. Always test with different input values and use print() statements to trace execution.

Overly deep nesting (more than 2-3 levels) often makes code hard to maintain. Consider refactoring with functions or clearer compound conditions.

Lesson Examples - if, elif, and else Statements

These examples demonstrate how to write and understand if, elif, and else statements in Python. Focus on program flow, correct ordering, and proper indentation.

Basic if Statement 

age = 18

if age >= 18:
    print("You are an adult.")

# Program flow: Only runs the indented block if the condition is True.

Multiple Independent if Statements 

temperature = 75
is_sunny = True
is_weekend = True

print("Checking weather conditions...")

if temperature > 70:
    print("It is warm.")

if is_sunny:
    print("The sun is shining.")

if is_weekend:
    print("It is the weekend.")

print("All checks completed.")

# Program flow: Each if is checked independently. 
# Multiple blocks can run if their conditions are True.

Key Point: Without elif or else, Python evaluates every if statement regardless of previous results.

if / else Block 

score = 65

if score >= 60:
    print("You passed!")
else:
    print("You did not pass. Keep trying!")

# Program flow: Exactly one of the two blocks will always run.

if / elif / else (Multi-way Decisions) 

grade = 85

if grade >= 90:
    print("Excellent! You got an A.")
elif grade >= 80:
    print("Good job! You got a B.")
elif grade >= 70:
    print("You got a C.")
elif grade >= 60:
    print("You got a D.")
else:
    print("You need to study more.")

# Program flow: Python checks conditions in order and runs only the first True block.

Correct Ordering and Rules

  • if must come first.
  • elif can only come after an if or another elif.
  • else must come last (if used).
  • Every block must be indented (usually 4 spaces).
  • Every condition line must end with a colon :.

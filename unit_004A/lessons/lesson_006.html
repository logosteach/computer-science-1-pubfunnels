Lesson Examples - Common Mistakes & Best Practices with Conditionals

These examples highlight the most common mistakes students make with if statements and show how to debug and write clear, maintainable conditional logic. Good code is not just correct — it is readable and trustworthy, just as clear thinking leads to wise living.

Mistake #1: Using = Instead of ==

One of the most common errors is using a single equals sign (=) when checking for equality. In Python, = is for assignment, while == is for comparison.

# ❌ Wrong - This assigns 10 to age instead of comparing
age = 18
if age = 18:          # SyntaxError!
    print("You are 18!")

# ✅ Correct
age = 18
if age == 18:
    print("You are exactly 18 years old.")

Output:

You are exactly 18 years old.
Warning: Using = inside an if condition causes a SyntaxError. Always use == for equality checks.

Mistake #2: Forgetting the Colon

Every if, elif, and else line must end with a colon (:).

# ❌ Wrong - Missing colon
score = 85
if score >= 90
    print("You got an A!")

# ✅ Correct
score = 85
if score >= 90:
    print("You got an A!")
elif score >= 80:
    print("You got a B!")
else:
    print("Keep working hard!")

Output:

You got a B!
Tip: The colon tells Python that a block of code is about to begin. Think of it as the "start of the decision block."

Mistake #3: Incorrect Indentation

Python uses indentation (usually 4 spaces) to define code blocks. Inconsistent or missing indentation causes IndentationError.

# ❌ Wrong - Inconsistent indentation
temperature = 75
if temperature > 70:
print("It's warm outside.")   # No indentation!
    print("You might want shorts.")  # Extra indentation

# ✅ Correct - Consistent 4-space indentation
temperature = 75
if temperature > 70:
    print("It's warm outside.")
    print("You might want shorts.")
else:
    print("It's a bit cool today.")

Output:

It's warm outside.
You might want shorts.
Warning: Mixing tabs and spaces is a common cause of hard-to-find indentation errors. Configure your editor to always use 4 spaces.

Debugging Conditional Logic

When your conditional logic isn't working as expected, use print() statements to trace which branch is being executed.

# Debugging example
age = 16
has_permission = True

print(f"Checking access for age={age}, has_permission={has_permission}")

if age >= 18:
    print("  Outer: Age requirement met.")
    if has_permission:
        print("    Inner: Permission granted.")
        print(">>> RESULT: Full access approved.")
    else:
        print("    Inner: No permission.")
        print(">>> RESULT: Access denied - need permission.")
else:
    print("  Outer: Age requirement NOT met.")
    print(">>> RESULT: Access denied - too young.")

Output:

Checking access for age=16, has_permission=True
  Outer: Age requirement NOT met.
>>> RESULT: Access denied - too young.
Tip: Add temporary print statements with clear labels like "Outer:", "Inner:", or "DEBUG:" to trace program flow. Remove them once the bug is fixed.

Best Practices for Readable Conditionals

Writing clear conditional code makes programs easier to understand, debug, and maintain.

# ✅ Good practices demonstrated
is_weekend = True
has_homework = False
energy_level = "high"

# 1. Use descriptive variable names
if is_weekend and not has_homework and energy_level == "high":
    print("Perfect time to go hiking!")

# 2. Keep conditions simple - extract complex logic into variables
is_eligible_for_discount = (age >= 65) or (is_student and has_coupon)

if is_eligible_for_discount:
    print("You qualify for a discount!")

# 3. Use early returns / guard clauses when appropriate (in functions)
def get_access_level(user):
    if not user.is_logged_in:
        return "guest"
    if user.is_admin:
        return "admin"
    return "user"

Key Best Practices:

  • Use meaningful variable names that describe the condition
  • Break complex conditions into named boolean variables
  • Keep if blocks short and focused
  • Add comments for complex logic
  • Be consistent with indentation and style

Before & After: Making Code More Readable

Here's a before-and-after example of improving conditional code.

# ❌ Before - Hard to read and understand
if age>=18 and (has_id==True or has_passport==True) and not (is_banned==True):
    print("Access granted")
else:
    print("Access denied")

# ✅ After - Clear and maintainable
is_adult = age >= 18
has_valid_id = has_id or has_passport
is_not_banned = not is_banned

if is_adult and has_valid_id and is_not_banned:
    print("Access granted")
else:
    print("Access denied")

The second version is much easier to read, debug, and modify later.

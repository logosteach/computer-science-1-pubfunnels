
# Lesson Narration Draft (Truthy and Falsy Values)

Today we’re exploring a powerful and sometimes surprising feature of Python: truthy and falsy values.

In Python, when an expression is evaluated in a Boolean context—like inside an if statement, certain values are automatically treated as “truthy” (they act like True) and others as “falsy” (they act like False). This happens even though the values themselves are not the Boolean True or False.
Here are the most common examples:

Empty strings (""), empty lists ([]), empty tuples (()), empty dictionaries ({}), and None are all falsy.
Any non-empty string, non-empty list, non-empty dictionary, or any non-zero number is truthy.

The number 0 (and 0.0) is falsy, while any other number is truthy.

This leads to a very Pythonic style called implicit Boolean checking. Instead of writing the longer if name != "":, you can simply write if name:. The code becomes cleaner and more readable because Python already knows how to evaluate the “truthiness” of the value for you.

It’s important to understand the difference between explicit and implicit evaluation. Writing if condition == True: is usually unnecessary and can sometimes hide bugs. Implicit truthy evaluation is the preferred, more elegant way in Python when you simply need to know whether a value has meaningful content.

# Word Document Creation Instructions

Computer labs, editable handouts, and other instructor-facing write-ups are created as **Word documents** (`.docx`), not PDFs, unless the instructor asks for a PDF.

Reason: a `.docx` file can be edited later without rebuilding a typeset PDF.

---

## When to use Word

- Computer labs
- Research labs
- Lab teacher notes that travel with the lab
- Any document the instructor says should stay editable

PDF is still allowed for locked student items such as tests, when the instructor asks.

---

## Style

Use the LogosTeach document palette:

- Navy `#0D3358`
- Navy dark `#0A2540`
- Teal `#1A7070`
- Gold `#E1A244`
- Rust `#A64936`
- Cream `#F6F6F5`
- Ivory `#FFF9F0`
- Ink `#2A2A2A` or `#222222`
- Code background `#E7F2FD`
- Footer `#E8EEF3`

Body font: Calibri or Arial. Code font: Consolas. Page: US Letter.

Keep Scripture in the New King James Version.

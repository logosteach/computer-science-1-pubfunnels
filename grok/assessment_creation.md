# Assessment Creation Instructions

Go to the following public link: https://github.com/logosteach/computer-science-1-pubfunnels/tree/main

You will find a templates folder. In this folder are several templates relevant for helping me with assessment creation and editing.

1. assessment_template.html # this contains the template for an actual assessment.
2. assessment_description_template.html # this contains a template for writing a meaningful and informative description of what is expected for my student to know before they take the assessment. This section should always have relevant and practical study tips and skills for the content that the student is being tested on.
3. When you help me create a question please make sure it is given in this type of html format:

<div class="question">
    <p><strong>X.</strong> [Question text here] (__ points)</p>
    <ul>
        <li>a) Option A</li>
        <li>b) Option B</li>
        <li>c) Option C</li>
        <li>d) Option D</li>
    </ul>
</div>

# PDF Creation Instructions

When creating a PDF document, use the color schemes found in the
`static/css/book_cover_colors.css` file and, when present,
`static/css/book_styles_2nd_edition.css`. Use these colors for headers,
blockquotes, and similar chrome.

The font color should be `#222`. The font-family for body text should be
Source Sans Pro / Source Sans 3.

**Computer labs are no longer created as PDFs.** Create a Word document
(`.docx`) instead. See `grok/computer_labs.md` and `grok/word_documents.md`.
Only make a lab PDF when the instructor explicitly asks for one.

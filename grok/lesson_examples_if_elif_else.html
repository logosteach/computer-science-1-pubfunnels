Lesson Examples - Conditional Statements: if, elif, else

These examples demonstrate how to use if, elif, and else statements to control program flow based on conditions. Proper indentation and the colon are essential.

Basic if Statement Example 

age = 18
if age >= 18:
    print("You are eligible to vote.")
else:
    print("You are not eligible to vote yet.")

Output:

You are eligible to vote.

Multi-way Decision with elif 

score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
print(f"Your grade is: {grade}")

Output:

Your grade is: B
Tip: The conditions are checked in order. Once a true condition is found, the rest are skipped.

Importance of Indentation and Colon

Python uses indentation (typically 4 spaces) to define code blocks. The colon : indicates the start of a block.

Incorrect indentation or missing colon will cause IndentationError or SyntaxError.

# Lesson 7 - Putting It All Together

Well now it is time to bring it all together. In this unit we have learned about for and while loops. We have learned about when to use them and the pitfalls new and experienced programmers can have when working with them. We have learned about the `range()` function with its off by one behavior in its end parameter, we have investigated how to break free from a loop using the `break` keyword, how to skip an iteration of a loop using the `continue` keyword, how to create a loop that does not have a full logical implementation using the `pass` keyword, and how to run a block of code, given the loop completes without a break procedure, using the `else` keyword.

Now it is time to put this all together. Here is the encouragement I would like to leave with you before you begin the final lesson for this unit.

***Ephesians 1:10 -*** *"That in the dispensation of the fulness of times He might gather together in one all things in Christ, both which are in heaven, and which are on earth; even in Him."*

The day has come and is coming when Christ will bring everything into one great **synthesis**. The process will be complete, and the world will once again become garden. What Adam lost, Christ has won back for His people, and for God. All creation will be united under the banner of our Lord Jesus Christ. There is no greater synthesis than that.

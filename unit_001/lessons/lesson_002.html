Lesson Examples - Arithmetic, Variable Naming Rules and Conventions

These examples practice the IDLE interactive shell: arithmetic operators, immediate feedback, and the difference between experimenting in the shell and running saved scripts. Variable naming is introduced as a foundation for later lessons.

Open and Use the IDLE Shell

Launch IDLE. At the >>> prompt, type a line and press Enter. Python evaluates it and shows a result (or an error).

Example 
# Type these one at a time at the >>> prompt:
print("Shell is interactive")
2 + 2

Output:

Shell is interactive
4
Tip: In the shell, a bare expression like 2 + 2 shows its value. In a saved script, use print() to display values.

Basic Arithmetic Operators

Practice the core operators and watch results appear immediately.

Example 
print(10 + 3)
print(10 - 3)
print(10 * 3)
print(10 / 3)    # true division → float
print(10 // 3)   # floor division
print(10 % 3)    # remainder
print(2 ** 4)    # exponent (2 to the 4th)

Output:

13
7
30
3.3333333333333335
3
1
16

Shell vs Saved Scripts

The shell is for quick trials. A script is a saved .py file you run as a whole program. Shell history is temporary; scripts are permanent and shareable.

Example 
# Shell: type line by line, see results now
# Script: write many lines, save as hello.py, run the file
print("This line could live in either place.")
print("Scripts are better for multi-step programs.")

Output:

This line could live in either place.
Scripts are better for multi-step programs.

Simple Syntax Errors in the Shell

The shell reports mistakes right away. Read the error message and fix the line.

Example 
# Broken examples (do not leave them broken—fix them):
# print("Hello"      → SyntaxError: missing closing quote
# 2 +                 → SyntaxError: incomplete expression
# print(2 + 2)        → correct

print(2 + 2)
print("Hello")

Output:

4
Hello
Watch out: SyntaxError means Python could not understand the line. Check quotes, parentheses, and complete expressions.

Variable Names (Foundation)

Names store values for later. Follow rules: start with a letter or underscore; use letters, digits, underscores; case-sensitive; prefer snake_case.

Example 
score = 95
player_name = "Ruth"
print(player_name, score)
# valid: total2, _temp, quiz_score
# invalid: 2total, quiz-score, class

Output:

Ruth 95

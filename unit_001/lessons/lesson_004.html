Lesson Examples - IDLE Script Editor

These examples move from the interactive shell to IDLE’s script editor: multi-line programs, saving files, comments, and the edit–run–fix cycle.

Open the Editor and Create a New File

In IDLE: File → New File (or equivalent). A blank editor window opens. This is where multi-line programs live.

Example 
# File: hello_script.py
# Created in IDLE: File → New File
print("My first saved script")
print("Each line runs in order from top to bottom")

Output:

My first saved script
Each line runs in order from top to bottom

Write, Save, and Run

Save as a .py file (File → Save). Run with Run → Run Module (often F5). Output appears in the shell window.

Example 
# save as greetings.py then press F5 (Run Module)
student = "Hannah"
print("Welcome,", student)
print("This file can be opened and run again tomorrow.")

Output:

Welcome, Hannah
This file can be opened and run again tomorrow.
Tip: Save before you run. Unsaved buffers can confuse beginners.

Shell vs Script (Again, With Purpose)

Shell: explore one idea quickly. Script: keep a complete program, share it, submit it, return to it later.

Example 
# Shell experiment (temporary):
# >>> 3 * 7
# 21
#
# Script version (permanent):
result = 3 * 7
print("3 * 7 =", result)

Output:

3 * 7 = 21

Comments with #

Comments document purpose for humans. Python ignores them.

Example 
# greet the user and show a simple total
name = "Micah"       # camper name
nights = 5           # length of stay
print("Camper:", name)
print("Nights:", nights)
# print("debug:", name, nights)  # optional debug line

Output:

Camper: Micah
Nights: 5

Edit, Debug, Re-run

When something is wrong: read the error in the shell, fix the editor line, save, run again. This loop is normal—not failure.

Example 
# Broken then fixed pattern:
# print("Hello)     # SyntaxError: missing quote
print("Hello")       # fixed
print(10 / 2)        # check your arithmetic output too

Output:

Hello
5.0
Watch out: Logic errors may run without crashing but print the wrong answer—always check results.

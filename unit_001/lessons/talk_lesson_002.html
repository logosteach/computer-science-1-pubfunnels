Lesson 002 - Arithmetic, Variable Naming Rules and Conventions — Talking Points

Key talking points and discussion notes for teaching using the IDLE shell, basic arithmetic, simple syntax errors, and foundations for variables.

Main Teaching Points

  • IDLE interactivity: Type → Enter → feedback. Ideal for first experiments.

  • Arithmetic set: + - * / // % ** — show live results.

  • Shell vs script: Temporary exploration vs saved, multi-line programs.

  • Read syntax errors: Quotes, parentheses, incomplete lines.

  • Naming preview: snake_case, rules, meaningful names.

  • Active engagement: Faith is not passive—parallel the interactive shell carefully.

Discussion & Talking Points

  • Question 1: What is the difference between typing 2 + 2 in the shell and putting it in a script without print?

  • Question 2: What does // do that / does not?

  • Question 3: Give one valid and one invalid variable name and explain why.

  • Question 4: How do you recover when the shell shows SyntaxError?

  • Question 5: How does interactive feedback in IDLE help us talk about actively engaging with God?

Biblical Integration

The IDLE shell is interactive—we type, we receive feedback, we respond again. Our walk with God is not passive. We actively engage: worship, hear the Word, read Scripture, pray with thanksgiving, and share the hope we have in Christ.

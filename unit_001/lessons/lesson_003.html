Lesson Examples - The Magnificent Print Function

These examples show why print() matters and how to output text, numbers, escape sequences, and simple formatted messages.

Purpose of print()

print() displays information for the user and for you while debugging. Without output, programs can run “silently” and hide mistakes.

Example 
print("Hello, world!")
print(42)
print("Answer:", 6 * 7)

Output:

Hello, world!
42
Answer: 42

Text, Numbers, and Combinations

You can print many types. Commas separate values with spaces by default.

Example 
name = "Eli"
score = 88
print(name)
print(score)
print(name, "scored", score, "points")

Output:

Eli
88
Eli scored 88 points

Escape Sequences: \n and \t

Use \n for a new line and \t for a tab indent inside a string.

Example 
print("Line 1\nLine 2")
print("Name:\tNoah")
print("A\tB\tC")

Output:

Line 1
Line 2
Name:	Noah
A	B	C

Commas vs + for Combining Output

Commas in print() convert values and insert spaces. The + operator concatenates strings only—convert numbers with str() if you use +.

Example 
age = 15
print("Age:", age)           # commas (easy)
print("Age: " + str(age))    # + needs strings

Output:

Age: 15
Age: 15
Watch out: print("Age: " + 15) raises TypeError. Convert with str(15) or use commas.

Simple Formatted Messages

Build clear messages students and users can read at a glance.

Example 
course = "Computer Science 1"
unit = 1
print("=" * 28)
print("Course:", course)
print("Unit:", unit)
print("Status:	Ready to learn")
print("=" * 28)

Output:

============================
Course: Computer Science 1
Unit: 1
Status:	Ready to learn
============================
Tip: Clear output is part of good programming—not an afterthought.

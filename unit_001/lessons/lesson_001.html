Lesson Examples - Downloading and Installing Python

These notes and examples walk through why we use Python, how to install it safely from official sources, how to verify the install, and how to open the IDLE shell for the first time.

Why Python?

Python is popular for beginners and professionals because its syntax is readable, it has a large standard library, and it is used in education, science, web work, automation, and more. You can start small in the shell and grow into full programs.

Example 
# You do not need to run this yet — it is a reminder of Python's readable style.
message = "Hello, Python!"
print(message)

Output:

Hello, Python!
Tip: Readable code is a gift to future you and to classmates who read your work.

Download and Install from Official Sources Only

Install Python from the official website (python.org) or your OS’s trusted store/package source. Avoid random third-party download sites. On installers, enable options such as “Add Python to PATH” when offered (Windows).

Example 
# Checklist (not runnable code — steps to complete on your computer)
# 1. Go to https://www.python.org/downloads/  (or your OS store)
# 2. Download the current Python 3.x installer
# 3. Run the installer
# 4. Finish the install
print("Install from a trusted source only.")

Output:

Install from a trusted source only.
Watch out: Untrusted downloads can include malware. Prefer python.org or official OS channels.

Verify the Installation

Open a terminal or command prompt and check the version. Seeing a Python 3.x version string means the install is reachable from the command line.

Example 
# In Terminal / Command Prompt / PowerShell (type these yourself):
#   python3 --version
#   # or on some Windows setups:
#   python --version
#
# Example of what success looks like:
print("Python 3.12.x")  # your version number may differ

Output:

Python 3.12.x
Tip: If the command is not found, Python may not be on PATH—revisit the installer options or your OS install notes in unit_001/etc.

Launch IDLE and Learn the Layout

IDLE (Integrated Development and Learning Environment) ships with Python. Open it from your applications menu or by running idle / idle3 on some systems. The shell window shows a prompt (>>>) where you type code and press Enter for immediate results.

Example 
# When IDLE opens, you will see something like:
# Python 3.x.x (... )
# Type "help", "copyright", "credits" or "license" for more information.
# >>>
#
# Try typing:
print(2 + 2)

Output:

4

Purpose of the IDLE Interface

The interactive shell is for quick experiments. Later you will also use IDLE’s editor for multi-line scripts. For now, focus on opening IDLE, reading the prompt, and running one-line commands successfully.

Example 
print("IDLE shell is ready for practice.")
print("Type an expression, press Enter, see the result.")

Output:

IDLE shell is ready for practice.
Type an expression, press Enter, see the result.

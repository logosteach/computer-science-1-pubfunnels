Lesson 003 - The Magnificent Print Function — Talking Points

Key talking points and discussion notes for teaching using print() for text and numbers, escape sequences, and clear formatted messages.

Main Teaching Points

  • Why print exists: Communication and debugging.

  • Multiple arguments: Commas insert spaces automatically.

  • \n and \t: Layout control in console text.

  • + vs commas: Type rules for concatenation.

  • Clarity as care: Colossians 4:6—gracious, purposeful speech.

Discussion & Talking Points

  • Question 1: Why is print useful even when a program “already works”?

  • Question 2: How do you print a blank line?

  • Question 3: What is the difference between print() and print("a" + "b")?

  • Question 4: Show a line that prints a name and a score on one line.

  • Question 5: How does clear program output parallel gracious, clear speech?

Biblical Integration

Intentional, clear output serves the person reading the screen. Scripture calls us to speech that is gracious and purposeful—words that fit the need.

Scripture (NKJV):
“Let your speech always be with grace, seasoned with salt, that you may know how you ought to answer each one.” (Colossians 4:6, NKJV)

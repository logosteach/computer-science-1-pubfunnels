Lesson Examples - VS Code - Downloading, Installing

These notes introduce Visual Studio Code: install the editor, add the official Python extension, create and run a .py file, and compare Code with IDLE—including how to choose extensions wisely.

Download and Install VS Code

Get Visual Studio Code from the official site (code.visualstudio.com) or a trusted OS store. Install like other applications for your platform (macOS, Windows, Linux).

Example 
# After install, you should be able to open "Visual Studio Code"
# or "Code" from your applications menu.
print("VS Code is a code editor — great for larger projects.")

Output:

VS Code is a code editor — great for larger projects.
Watch out: Use official sources for the editor, just as you did for Python.

Install the Official Python Extension

Open Extensions in VS Code, search for Python published by Microsoft, and install it. This enables highlighting, run helpers, and language support.

Example 
# Extension checklist:
# 1. Click Extensions (sidebar)
# 2. Search: Python
# 3. Publisher: Microsoft
# 4. Install
print("Python extension helps VS Code understand .py files.")

Output:

Python extension helps VS Code understand .py files.

Create, Open, Write, Save, Run

Create a folder for your course work, open it in VS Code, add a new file ending in .py, write code, save, then run with the Run button or the integrated terminal.

Example 
# File: vs_code_hello.py
print("Running from VS Code")
print(2 + 2)

# Terminal example (integrated terminal):
#   python3 vs_code_hello.py

Output:

Running from VS Code
4
Tip: If Run fails, confirm the selected Python interpreter matches the Python you installed.

IDLE vs VS Code

IDLE is simple and ships with Python—excellent for first steps. VS Code is a full editor: folders, extensions, Git, multi-file projects. Use IDLE for quick starts; grow into VS Code as programs get larger.

Example 
print("IDLE: simple shell + basic editor, bundled with Python")
print("VS Code: professional editor, extensions, multi-file work")
print("Both can run the same Python language.")

Output:

IDLE: simple shell + basic editor, bundled with Python
VS Code: professional editor, extensions, multi-file work
Both can run the same Python language.

Marketplace Safety

Extensions add power and risk. Prefer well-known publishers, high install counts, and clear descriptions. Avoid obscure extensions that ask for unnecessary permissions or come from unknown authors.

Example 
# Before installing an extension, ask:
# - Who is the publisher?
# - Is it the official / widely used option?
# - Do recent reviews report malware or breakage?
print("Install extensions carefully — quality over quantity.")

Output:

Install extensions carefully — quality over quantity.
Watch out: Malicious extensions exist. When unsure, do not install.
